# 기록 — 실제로 발행한 브리프와 결과

상세페이지 생성 AI 프로젝트에서 2026-09-09 ~ 2026-10-05 에 쓴 오케스트레이션 런타임 폴더
(`.orchestration/`)의 사본이다. 그 프로젝트에서는 git 에 올리지 않던 폴더다.

문서 안의 `.orchestration/...` 경로는 이 폴더의 같은 이름 아래에 있다
(예: `.orchestration/tasks/20260910-105816-codex.md` → `records/tasks/20260910-105816-codex.md`).

## 가린 것

원문을 그대로 옮기되 아래 값만 바꿨다. 그 밖의 문장은 고치지 않았다.

| 표시 | 원래 값 |
| --- | --- |
| `<repo>` | 프로젝트 저장소의 로컬 절대 경로 |
| `~` | 사용자 홈 디렉터리 경로 |
| `<scratchpad>` | 지휘자 세션의 임시 폴더 경로 |
| `<ubuntu-server>`, `<mac-ip>` | 사내 테스트 서버와 작업 PC 의 사설 IP |
| `<user>` | 서버 로그인 계정 |
| `<aws-account>` | AWS 계정 번호 |
| `<test-domain>` | 테스트용 도메인 |
| `<test-token>` | 테스트 환경에만 쓰던 토큰 값 |
| `<redacted>` | Figma 파일 링크, Claude 세션·아티팩트 링크의 식별자 |

## 넣지 않은 것

- `reports/` 의 실증 테스트 증거 (화면 캡처·로그·JSON, 약 38MB). 로그와 JSON 에 사내 서버 주소가 섞여 있다.
- `scratch/` 의 측정 스크립트와 결과 파일. 프로젝트 코드에 묶여 있어 여기서는 실행되지 않는다.

## 읽을 때 알아 둘 것

- 브리프가 가리키는 `src/…`, `tests/…`, `docs/…` 는 프로젝트 저장소의 경로라 이 저장소에는 없다.
- 워커의 `## 결과` 는 검증 전의 보고다. 지휘자가 무엇을 수용하고 무엇을 기각했는지는
  [`../docs/orchestration-usage.md`](../docs/orchestration-usage.md) 와 `reports/audit-2026-09-16/00-final.md` 에 있다.
- `## 결과` 가 없는 브리프도 있다 (`orc task` 로 발행한 174건 중 9건).
