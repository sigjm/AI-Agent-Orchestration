## 지시

## 목표

제품 유형별 배경 씬 분기가 평가 데이터셋 전체를 얼마나 커버하는지 수치로 보여주는
진단 스크립트 `scripts/check_scene_direction_coverage.py` 를 새로 만든다.

## 배경

`src/detail_page_ai/prompts.py` 의 `_product_scene_direction(profile)` 은 제품 정보에서
한국어 키워드를 매칭해 배경 씬 방향을 고른다. 분기는 tea / box / textile / ceramic / metal /
wood 그리고 기본값이다. 그런데 파일럿 6건을 확인해 보니 **금·보석 목걸이가 metal 분기로
오분류**됐다. 장신구 전용 분기가 없기 때문이다. 이런 오분류와 기본값 남용을 자동으로
찾아내는 도구가 필요하다.

지금 다른 워커가 이 함수에 장신구 분기를 추가하고 키워드를 보강하는 중이다. 네 도구는
그 수정 전후를 비교 판정하는 데 쓰인다.

## 요구사항

- `_product_scene_direction` 을 **직접 import 해서 호출한다.** 키워드 매칭 로직을 네가 다시
  구현하지 마라. 그러면 원본이 바뀔 때 진단이 거짓이 된다.
  (`sys.path` 에 `src` 를 넣는 방식은 `scripts/run_eval_pilot.py` 를 참고하라.)
- 판정 대상 입력 두 가지를 지원한다.
  1. `--pilot-dir <경로>`: 파일럿 산출물의 `analysis-*/result_summary.json` 에 들어 있는
     실제 product 정보로 판정한다. 이게 기본 사용법이다.
  2. `--dataset`: `data/evaluation/cma_real_v1/manifest.json` 의 60건에 대해,
     `sources/<asset_id>.json` 의 제목·재질 정보로 최소한의 product 프로필을 만들어 판정한다.
     실제 파이프라인 출력이 아니라 근사치이므로 출력에 "근사 판정" 이라고 명시하라.
- 어느 분기에 떨어졌는지 판정하려면 반환된 dict 를 각 분기의 고유 문자열과 대조하면 된다.
  (예: `setting` 값에 "bookcase" 가 있으면 box 분기) 판정 방법은 네가 정하되, 새 분기가
  추가돼도 깨지지 않게 **미리 정의한 목록에 없으면 "미상"으로 표시**하고 그 setting 값을
  같이 출력하라. 절대 조용히 기본값으로 뭉개지 마라.
- 출력: 카테고리별로 어느 분기에 몇 건이 떨어졌는지 표, 그리고 **기본값(default) 으로 떨어진
  건수와 그 목록**. 기본값이 하나라도 있으면 종료 코드 1.
- `--json <경로>` 로 같은 내용을 JSON 저장.
