## 1. 로그가 실제 동작과 반대로 말한다 (반드시 고칠 것)

react_document_builder.py 의 gallery 분기에 추가한 warning 블록 문제다.
`gallery` 는 `_DEFAULT_PHOTO_BY_BLOCK` 에 없으므로 default_photo_id 가 항상 None 인데,
다른 분기에서 쓰던 문구를 그대로 복사해 왔다. 재현하면 이렇다.

    photo_ids=['bogus'], available={'hero','detail','detail-02'~'detail-05'}

    로그  : photo_id 'bogus' ... default photo_id None is unavailable; omitting image
    반환값: ['detail','detail-02','detail-03','detail-04','detail-05']

이미지를 뺀다고 로그를 남기고는 실제로는 5장을 넣는다. 운영 중에 이 로그를 보면
정반대로 판단하게 된다. "default photo_id None is unavailable" 도 의미 없는 문장이다.

갤러리는 생성컷이 있으면 모델 출력을 **의도적으로 무시하는 것**이 정책이다.
실패처럼 보이는 문구를 쓰지 말고 실제로 일어난 일을 적어라. 예를 들어

    "gallery block requested %r but generated detail cuts are present; using %r instead"

정도로, 요청한 id 와 최종 확정된 id 를 함께 남기면 된다. 문구는 네가 정하되
**로그가 실제 반환값과 일치해야 한다.** 그리고 이 동작을 고정하는 테스트를
하나 추가해라(caplog 로 확인).

## 2. photo_slots.py 의 `available is None` 분기는 죽은 코드다

호출부가 둘뿐인데 어느 쪽도 None 을 넘기지 않는다.
- react_document_builder: `available_photo_ids is None` 은 그 앞에서 이미 걸러진다
- html_renderer: photo_uris 는 항상 dict 다

쓰지 않는 분기 때문에 dedup 로직이 두 벌로 복제돼 있다. 분기를 지우고
dedup 은 한 벌만 남겨라. 시그니처의 `Collection[str] | None` 도 `Collection[str]` 로 좁혀라.

겸사겸사 `deduplicated[:5]` 의 5 는 `len(GALLERY_SLOTS)` 로 바꿔라.
react_document_builder 에서는 이미 그렇게 쓰고 있어서 지금 두 파일이 서로 다르다.

### 2. 1번 문제 재현 검증 (재현 소멸 확인)

동일 입력(`photo_ids=['bogus']`, `available={'hero', 'detail', 'detail-02'~'detail-05'}`) 실행:

```bash
$ PYTHONPATH=src .venv/bin/python -c "
import logging
from detail_page_ai.dto import ApprovedDraftDto, PageBlockDto
from detail_page_ai.react_document_builder import build_react_document_from_draft, collect_referenced_photo_ids

logging.basicConfig(level=logging.WARNING, format='%(levelname)s: %(message)s')

draft = ApprovedDraftDto(
    product_name='테스트',
    summary='요약',
    hero_headline='헤드라인',
    hero_description='설명',
    page_plan=[PageBlockDto(section_id='gallery', block_type='gallery', photo_ids=['bogus'])],
)
available = {'hero', 'detail', 'detail-02', 'detail-03', 'detail-04', 'detail-05'}
doc = build_react_document_from_draft(draft, available_photo_ids=available)
print('REFERENCED_IMAGES:', sorted(collect_referenced_photo_ids(doc)))
"
```

**출력 결과:**
```
WARNING: gallery block requested ['bogus'] but generated detail cuts are present; using ['detail', 'detail-02', 'detail-03', 'detail-04', 'detail-05'] instead
WARNING: photo_id 'bogus' requested by gallery block is unavailable; using ['detail', 'detail-02', 'detail-03', 'detail-04', 'detail-05'] instead
REFERENCED_IMAGES: ['detail', 'detail-02', 'detail-03', 'detail-04', 'detail-05']
```
- `default photo_id None is unavailable` 삭제 확인.
- `omitting image` 삭제 확인.
- 로그 메시지와 실제 반환/참조 이미지(`['detail', 'detail-02', 'detail-03', 'detail-04', 'detail-05']`)가 완전히 일치함.
