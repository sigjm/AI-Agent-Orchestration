# 콜백을 BE 정본 경로로 조립해 보내기

- 워커: codex

## 지시

[구현 과제] BE 콜백 경로 조립 (AI-D1 해소)

## 배경 — BE 회신으로 확정된 사실

BE 가 2026-09-18 문서(커밋 8a6df578)로 정본 경로를 확정했다.

```
POST /internal/generations/{generationId}/completion
Authorization: Bearer {BACKEND_AUTH_TOKEN}
Idempotency-Key: {generationId}
Content-Type: multipart/form-data
```

이전 문서의 `/complete/multipart`, `/complete/json` 은 BE 가 오기재였다고 정정했다.

## 문제

`src/detail_page_ai/backend_client.py:159` 가 `self.url` 로 **설정값을 그대로**
POST 한다. `BACKEND_URL` 은 단일 주소라 건마다 다른 `{generationId}` 경로를
조립하지 못한다. 그래서 지금까지 콜백을 수동으로 보내야 했다.

## 할 일

1. `BACKEND_URL` 을 **기저 주소**로 다루고, 콜백 URL을 조립한다.
   기본 경로는 `/internal/generations/{generation_id}/completion` 이다.
   BE 가 이 경로를 한 번 바꾼 전례가 있으므로 `BACKEND_CALLBACK_PATH` 설정으로
   덮어쓸 수 있게 하되, 기본값을 위 경로로 둔다. 설정 이름은 config.py 의
   기존 alias 방식(`BACKEND_URL`, `BACKEND_AUTH_TOKEN`)과 같은 규칙을 따라라.
   기저 주소 끝의 슬래시 유무에 관계없이 정상 조립돼야 한다.
2. `Idempotency-Key` 를 확인하라. BE 문서는 `{generationId}` 를 요구한다.
   현재 코드는 `request.idempotency_key` 를 보낸다. **둘이 같은 값인지 먼저
   확인하고**, 다르면 BE 요구대로 generation_id 를 보내도록 고쳐라.
   같다면 고치지 말고 같다는 사실을 보고하라.
3. multipart 필드 구성이 BE 가 읽는 것과 맞는지 코드 기준으로 확인하고,
   어긋나는 게 있으면 보고만 하라(고치기 전에 내 판단을 받아라).

## 하지 말 것

- 콜백을 보내는 시점(초안 시점 vs 승인 후)은 이번 과제 범위가 아니다. 미해결
  안건(BE-11)이므로 건드리지 마라.
- 사진 검증 로직(allowed_generated_reference 부분)은 건드리지 마라.

## 테스트

기존 콜백 테스트를 새 조립 방식에 맞게 고치고, 최소한 다음을 보장하라.
- 기저 주소 + generation_id 로 올바른 URL 이 만들어진다 (슬래시 유무 양쪽)
- `BACKEND_CALLBACK_PATH` 오버라이드가 동작한다
- `BACKEND_URL` 미설정 시 기존 동작(전달 보류)이 유지된다

단언을 약하게 만들지 마라. `.venv/bin/python -m pytest` 전체를 돌리고 숫자를
그대로 보고하라.
