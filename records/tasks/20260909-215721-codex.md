## 지시

## 문제

구조 점검에서 나온 항목이다. `scripts/` 가 성격이 다른 네 종류를 한 디렉터리에 평면으로
담고 있어 무엇이 무엇인지 알 수 없다.

- 데이터셋 구축: `setup_real_eval_dataset.py`, `build_detail_page_eval_dataset.py`,
  `build_training_dataset.py`, `build_flux2_product_scene_50.py`
- 실행: `run_local_detail_page.py`, `generate_attached_detail_page.py`, `build_detail_page_html.py`,
  `render_detail_page.mjs`
- 브라우저 테스트: `test_draft_preview.mjs`, `test_draft_preview_remote.mjs`,
  `test_input_page.mjs`, `test_detail_page_layout.mjs`
- 오케스트레이션: `orchestration/`

특히 `scripts/test_*.mjs` 는 이름이 테스트인데 `tests/` 밖에 있어 혼동을 부른다
(pytest `testpaths=["tests"]` 라 충돌은 없다).

## 작업

`scripts/` 아래에 성격별 하위 디렉터리를 만들고 파일을 옮긴다. 디렉터리 이름은 네가 정하되
위 네 분류를 반영하고, 기존 `orchestration/` 과 어울리는 명명을 써라.

**파일을 옮길 때 `git mv` 를 사용하라.** 이력이 끊기지 않는다.

옮긴 뒤 **참조를 전부 따라가서 고쳐라.** 최소한 다음을 확인한다.

- `README.md` 안의 스크립트 경로
- `docs/**` 안의 스크립트 경로 (`grep -rn "scripts/" docs/ README.md`)
- `package.json` 의 script 항목
- 스크립트끼리 서로를 참조하는 경로, 그리고 각 스크립트가 계산하는 `PROJECT_ROOT`
  (`Path(__file__).resolve().parents[1]` 같은 코드는 디렉터리가 한 단계 깊어지면 **깨진다**.
  `parents[2]` 로 고쳐야 한다. 이걸 놓치면 전부 망가진다. 옮긴 파이썬 스크립트를 하나씩
  `--help` 로 실행해 경로 계산이 맞는지 확인하라.)

## 절대 옮기면 안 되는 것

**평가 스크립트 4종은 이번에 건드리지 마라.** 지금 다른 워커가 이 중 하나로 6건 재생성을
실행 중이라, 옮기면 실행이 깨진다.

- `scripts/run_eval_pilot.py`
- `scripts/check_cutout_fidelity.py`
- `scripts/check_scene_direction_coverage.py`
- `scripts/build_review_sheet.py`

이 넷은 `scripts/` 최상위에 그대로 두고, 결과 보고에 "다음 차수에 evaluation 하위로 옮길 것"
이라고 남겨라.

## 구조 테스트 갱신

`tests/test_project_layout.py` 를 새 구조에 맞게 갱신한다. 이 저장소는 구조 규약을 문서가
아니라 테스트로 강제하는 방식을 쓴다. 새 디렉터리 배치가 유지되도록 정규 경로 검사를 추가하고,
옛 경로가 남아 있으면 실패하도록 레거시 경로 검사도 넣어라.

## 합격 기준

- `.venv/bin/python -m pytest -q` 전체 통과. 기존 테스트를 고쳐서 통과시키지 마라.
- `grep -rn "scripts/" README.md docs/ package.json` 결과에 옛 경로가 하나도 남지 않아야 한다.
- 옮긴 파이썬 스크립트가 각각 `--help` 로 정상 기동해야 한다 (경로 계산 검증).

## 하지 말 것

- `src/`, `generated/`, `data/` 는 건드리지 마라. `docs/` 는 **경로 참조 수정만** 허용한다
  (다른 워커 둘이 지금 `README.md` 와 `docs/architecture/` 를 각각 수정 중이니,
  그 파일에서는 스크립트 경로 문자열만 고치고 다른 문장은 손대지 마라).
- 모델 서버(11234) 끄기 금지 (재생성 실행 중), git commit / push 금지.
