## 지시

누끼(rembg)로 딴 실제 제품을 생성 배경 위에 합성하는 방식을 활용 장면의 기본 경로로 만듭니다. 관리자 지시: "rembg로 누끼 따고 배경 합성".

rembg 누끼는 방금 채택·커밋됐습니다(`cfd60bb`). 60장 전부 누끼가 나옵니다.

## 현재 흐름 (`src/detail_page_ai/source_photos.py` 의 `generate`, 누끼 성공 분기)
- hero: 원본 그대로 (`source_original`) — **건드리지 마세요.**
- packshot: 누끼를 흰 단색 배경에 합성 (`source_composite`).
- detail: 원본 크롭.
- **lifestyle: `_generated_usage_scene` 을 먼저 시도**합니다. 이것은 flux 로 원본 사진을 편집해 **제품까지 새로 그린** 장면입니다(`asset_mode="generated_scene"`, `product_generated=True`). 이것이 실패할 때만 `_background_for(role="lifestyle")` 로 제품 없는 배경판을 생성하고 `_composite` 로 누끼를 얹습니다.
- scale: `preserve_arrangement` 가 아니면 `_background_for(role="scale")` + `_composite`.
- detail-02~05: `_generated_detail_view` (flux 로 다른 각도 생성). **이번 작업 범위 밖입니다. 그대로 두세요.**

## 바꿀 것
1. **누끼가 있으면 lifestyle 은 "생성 배경 + 누끼 합성"을 먼저 씁니다.** 제품 픽셀은 원본, 배경만 생성합니다(`source_composite`, `background_generated=True`, `product_generated=False`). 배경 생성이 실패하면(`background_generator` 없음·오류) 그때 기존 `_generated_usage_scene` 으로 물러서거나, 그것도 안 되면 단색 배경 합성으로 떨어지게 하세요. 우선순위를 코드 주석에 남기세요.
2. **누끼가 없는 분기(`cutout is None`)는 그대로** 둡니다. 합성할 제품이 없으니 flux 편집이 유일한 수단입니다.
3. 합성 품질을 보세요. 지금 `_composite` 는 lifestyle 에서 제품을 캔버스 50% 크기로 줄여 아래쪽에 두고 접촉 그림자를 그립니다. 생성 배경판과 원근·조명이 안 맞으면 붙여 넣은 티가 납니다. 배경 프롬프트(`src/detail_page_ai/prompts.py` 의 `build_usage_context_background_prompt`, `build_background_prompt`)가 **제품이 놓일 빈 바닥면·정면 시점·부드러운 조명**을 요구하는지 확인하고, 필요하면 조정하세요. 배치 크기·위치·그림자 값을 바꾸면 이유를 주석에 남기세요.
4. scale 도 같은 방식(생성 배경 + 누끼)이 이미 기본인지 확인하고, 아니라면 lifestyle 과 맞추세요.
