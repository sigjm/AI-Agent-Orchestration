# 문서 수정 — 모델을 S3 사전 업로드분에서 읽는 방식으로

## 배경
인프라팀이 모델을 **S3 에 미리 올려두고 GPU Pod 가 S3 Gateway Endpoint 로 받는** 방식을 제안했고(`jangin-{env}-s3-models`, NAT 미경유·무료·빠름), 관리자가 확정했습니다.

역할 분담이 이렇게 정해졌습니다.
- **인프라팀**: S3 → PVC 동기화 (initContainer 또는 Job 의 `aws s3 sync`)
- **우리**: PVC 의 **로컬 디렉터리만 읽습니다.** 컨테이너에 AWS CLI·boto3·IAM 권한이 **들어가지 않습니다**

코드는 다른 워커가 동시에 고치는 중이며 **확정 사양**은 다음과 같습니다. 이 내용으로 문서를 쓰세요.
- 모델 경로가 **디렉터리로 존재하면** 로컬 모드 — `--revision` 을 전달하지 않고 `HF_HUB_OFFLINE=1` 로 네트워크를 시도하지 않음
- 그렇지 않으면 HF 모드 — 지금처럼 저장소 ID + `--revision <커밋SHA>`
- 텍스트·이미지 서버가 각각 독립 판정
- 로컬 모드인데 `config.json` 이 없으면 명확한 메시지와 함께 기동 중단

## 고칠 것

### 1. "S3 접근 필요 없습니다" 를 정정
`eks-workload-spec.md:134-136` 의 「S3 등 AWS Resource 접근 필요 여부」 절이 **"필요 없습니다"** 로 되어 있습니다. 이 답을 다음 취지로 다시 쓰세요.

- **우리 컨테이너는 여전히 AWS 자격이 필요 없습니다.** boto3·AWS CLI 의존성이 없고 IAM 역할도 필요 없습니다. 이 점은 그대로입니다.
- 다만 **모델 확보 방식이 바뀝니다.** 이전 답변은 첫 기동 때 Hugging Face 에서 약 30GB 를 내려받는 전제였습니다. 이제 **인프라팀이 S3(`jangin-{env}-s3-models`)에서 PVC 로 동기화**해 주시고, 우리는 그 디렉터리를 읽습니다.
- **앞선 답변이 달라진 점을 숨기지 말고 명시하세요.** "이전 답변에서는 …라고 말씀드렸으나, S3 사전 업로드 제안에 따라 다음과 같이 바뀝니다" 형태로.
- 산출물 저장은 여전히 PVC 입니다. 이 부분은 변경 없습니다.

### 2. 인프라팀에 필요한 것을 구체적으로 적기
- **동기화 대상 2개**
  | 모델 | 저장소 | 용도 | 크기 |
  | --- | --- | --- | --- |
  | 텍스트·비전 | `cyankiwi/Qwen3.8-27B-AWQ-INT4` (커밋 `6e134bae811fb5adac50ee042ae5f029ac6779aa`) | SGLang 텍스트 서버 | 가중치 19.6 GiB |
  | 이미지 확산 | `circulus/FLUX.2-klein-9B-bnb-4bit` (커밋 `58c2804f31af12c8888504b96250010c50b55e44`) | SGLang 확산 서버 | 약 10.2 GiB |
- **디렉터리 구조 요구**: SGLang 은 `config.json` 과 가중치 파일(`*.safetensors`)이 들어 있는 **디렉터리**를 가리켜야 합니다. 압축본이 아니라 펼쳐진 형태여야 하고, 모델마다 별도 디렉터리여야 합니다.
- **주입할 환경변수**: `TEXT_MODEL_PATH`·`IMAGE_MODEL_PATH` 에 PVC 안의 디렉터리 절대 경로를 넣어 주시면 됩니다. 예시 경로를 하나 제시하세요(`/var/lib/detail-page-ai/models/...` 하위).
- **순서 의존**: 동기화가 끝나기 전에 파드가 뜨면 기동이 실패합니다. initContainer 로 두거나 준비 완료를 보장해 주셔야 합니다. 우리 컨테이너는 이 경우 **명확한 오류 메시지를 남기고 즉시 종료**합니다.
- **버전 고정**: 로컬 모드에서는 `--revision` 이 적용되지 않습니다. **어떤 커밋의 가중치를 올렸는지는 S3 쪽에서 관리**해야 합니다. 위 표의 커밋 SHA 를 기준으로 삼아 주시길 요청하세요.

### 3. 달라지는 운영 특성
- 첫 기동에 30GB 를 받지 않으므로 **기동이 빨라집니다.** `startupProbe` 여유를 이전만큼 크게 잡지 않아도 됩니다. 다만 **정확한 시간은 실측 전**이므로 단정하지 마세요.
- 「함께 알아 두셔야 할 사항」의 "첫 기동이 오래 걸립니다 · 모델 약 30GB 다운로드" 서술을 이 방식에 맞게 고치세요.
- PVC 용량 권장(100Gi)은 그대로 유효합니다 — 모델이 여전히 PVC 에 있습니다.

### 4. `aws-migration-checklist.md`
모델 확보 방식이 바뀐 점을 반영하세요. 이 문서는 EKS·EC2 양쪽을 다루므로, **단일 EC2 compose 구성은 여전히 HF 다운로드**라는 점과 혼동되지 않게 구분해서 적으세요.
