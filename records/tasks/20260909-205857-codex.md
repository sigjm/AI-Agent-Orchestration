## 지시

## 1차 결과 확인 (당신이 방금 고친 것)

경계 연결 flood fill 수정은 의도대로 동작했다. 실측:

- textile (cma-102980): 보존율 26% -> **85%**, 시각적으로 완벽. 붉은 실선까지 살아났다.
- ceramic (cma-122443): 보존율 3% -> **62%**, 병 전체가 복구됐다.
- box / metalware / jewelry / furniture: 수정 전후 모두 `extract` 가 None 을 반환해
  원본 fallback 으로 간다. 회귀 없음.

테스트 240개 통과도 확인했다. 여기까지는 좋다.

## 남은 문제

ceramic 컷아웃을 중립 배경에 합성해 보면, 병 주위에 **원본 사진의 그림자와 배경
그라디언트가 전경으로 딸려 들어와 회색 얼룩**으로 남는다. 병 좌우와 아래에 넓은 회색
덩어리가 보인다. 모서리 평균 배경색(밝은 크림색)과는 거리가 멀어서 전경으로 판정되지만,
이건 제품이 아니라 촬영 배경이다.

직접 확인하려면 이렇게 하면 된다 (원본 `data/evaluation/cma_real_v1/images/cma-122443.jpg`):
추출한 `rgba_png` 를 중립색 캔버스에 alpha 로 합성해 저장하고 눈으로 본다.

## 목표

제품은 유지하면서 촬영 배경·그림자 잔재를 배경으로 되돌린다.

가능한 접근은 여러 가지다. 예를 들어 최대 연결 성분만 남겨 분리된 얼룩을 제거하거나,
전경 중 채도가 매우 낮고 밝기가 배경 쪽으로 완만하게 이어지는 테두리 영역을 배경으로
되돌리는 식이다. 방법은 네가 정하되, **제품을 깎아내지 않는 것이 절대 우선**이다.
애매하면 덜 깎는 쪽을 택하라. 제품이 지워지는 것이 이 작업의 원래 결함이었다.

## 합격 기준 (반드시 수치로 확인하고 보고에 표로 적을 것)

`scripts/check_cutout_fidelity.py` 와 같은 방식(원본 대비 비배경 픽셀 보존율)으로 측정한다.
그 스크립트는 다른 워커가 만든 것이니 읽어서 참고하되 **수정하지 마라**.

1. ceramic (cma-122443): 보존율 **0.55 이상** 유지. 그림자 얼룩이 눈에 띄게 줄어야 한다.
2. textile (cma-102980): 보존율 **0.80 이상** 유지. 지금 85% 에서 떨어뜨리지 마라.
3. box, metalware, jewelry, furniture: `extract` 가 계속 None 을 반환해야 한다
   (원본 fallback 유지). 여기서 갑자기 컷아웃이 생기면 회귀다.
4. `.venv/bin/python -m pytest -q` 240개 전부 통과. 기존 테스트를 고쳐서 통과시키지 마라.
5. 그림자 억제 로직에 대한 회귀 테스트를 `tests/test_source_photos.py` 에 추가한다.
