## 지시

'참고용' 라벨이 산출물 계약에서 탈락하는 결함을 수정합니다. 이전에는 기록만 하기로 했으나 관리자가 수정을 지시했습니다.

## 현상 (실측 확인 완료)

- `src/detail_page_ai/source_photos.py:793`, `:834` 가 생성 이미지에 label="AI 생성 활용 장면(참고용)", label="AI 생성 디테일(참고용)" 을 붙입니다. `result_summary.json` 에는 케이스당 5회 '참고용'이 남습니다.
- 그런데 `react_document.json` 의 '참고용' 출현 횟수는 전 케이스 0회입니다 (9차 6건 실측).
- 원인: `src/detail_page_ai/react_document_builder.py:585 build_react_document_from_draft` 가 `ApprovedDraftDto` 만 받습니다. 사진 메타데이터에 접근할 수 없어서, `_image_figures` (같은 파일 221행 부근)가 `alt` 를 `f"{product_name} {alt_label}"` 로 합성할 뿐 `label` 을 싣지 못합니다.
- `src/detail_page_ai/html_renderer.py` 도 `generated_scene` 여부로 분기만 하고 라벨을 그리지 않습니다.

## 요구사항

1. 생성 이미지(즉 `product_generated=true` 인 사진)에 대해 '참고용' 표시가 **react_document.json 과 최종 렌더 HTML 양쪽에** 실제로 나타나야 합니다.
2. 원본 유래 컷(`product_generated=false`)에는 라벨을 붙이지 마세요. 원본 사진을 AI 생성물로 오인시키면 안 됩니다.
3. 라벨 문구는 새로 지어내지 말고 `GeneratedPhotoMetadataDto.label` 에 이미 들어 있는 값을 그대로 쓰세요. 이 DTO 는 `src/detail_page_ai/dto.py:459` 에 있고 `label` 과 `product_generated` 를 모두 갖고 있습니다.
4. `build_react_document_from_draft` 의 시그니처를 바꾸게 되면 호출부를 전부 고치세요. 현재 호출부는 `src/detail_page_ai/pipeline.py:199`, `:536`, `:641`, `src/detail_page_ai/dto.py:419` 입니다. 사진 메타데이터가 없는 경로에서는 라벨 없이 기존과 동일하게 동작해야 합니다(하위 호환).
5. react_document 스키마를 넓히는 경우, 기존 소비자가 깨지지 않도록 선택적 필드로 하세요. FE 는 우리 상대편이므로 계약 변경 사실을 명확히 남기세요.

## 결과

### 변경 파일

- `src/detail_page_ai/react_document_builder.py`: `build_react_document_from_draft(..., *, generated_photos=None)`로 선택적 사진 메타데이터를 받습니다. `product_generated=True`인 사진의 DTO `label` 원문만 해당 `figure` 안의 `figcaption` 텍스트 노드로 내보냅니다. 원본 사진과 메타데이터 없는 호출은 기존 AST를 그대로 유지합니다.
- `src/detail_page_ai/pipeline.py`: 본 생성 경로는 검증된 `photo_metadata` 생성 뒤 React 문서를 구성하도록 순서를 옮겼고, 복구 경로는 저장된 사진 메타데이터를 전달합니다. 미리보기·완료 응답처럼 사진 메타데이터가 없는 호출은 선택 인자의 기본값을 사용합니다.
- `src/detail_page_ai/html_renderer.py`, `web/detail_page.css`: 서버 렌더가 허용된 생성 사진의 `ProductPhoto.label`을 보존해 이미지 위 `figure > figcaption.generated-photo-label`로 실제 출력합니다. `product_generated=False` 사진은 라벨 맵에 포함하지 않습니다.
- `tests/test_react_document.py`, `tests/test_html_renderer.py`: 생성 사진만의 원문 라벨 출력과 원본 사진 라벨 미출력을 각각 추가 검증했습니다.

### FE 계약 변경

`react_document`의 JSON 스키마 필드는 넓히지 않았습니다. 기존에 허용된 `figure`·`figcaption` 요소를 사용하며, 생성 사진의 figure에만 선택적으로 `figcaption` 자식과 원문 라벨 텍스트가 추가됩니다. 따라서 기존 소비자는 새 props를 해석할 필요가 없고, 라벨을 렌더하는 FE는 해당 figcaption을 표시하면 됩니다.
