## 1. 누끼를 rembg 로

현재 `SolidBackgroundCutoutExtractor`(모서리 4점 평균 배경색 + 테두리 플러드 필)는 판매용 사진에서는 통과하지만 그라데이션 배경에서는 85% 폴백합니다. 이것을 rembg 로 교체합니다.

- rembg 2.0.83, onnxruntime 1.29.0 이 `.venv` 에 이미 설치돼 있습니다. **`pyproject.toml` 의존성에 선언**하세요(현재 없음).
- u2net 모델 캐시(`~/.u2net`)가 없어서 첫 호출 때 모델을 내려받습니다. 이 동작을 확인하고, 테스트가 네트워크나 실제 모델에 의존하지 않도록 rembg 호출을 주입 가능하게 만드세요(테스트에서는 가짜 세그멘터). 기존 추출기가 생성자 인자로 주입되는 구조를 따르면 됩니다.
- 모델 선택(`u2net`, `isnet-general-use`, `birefnet-general` 등)은 판단하되, 고른 이유를 주석에 남기세요. 반투명 소재(꽃잎)·광택 표면(나전)에서 가장자리를 보존하는지가 기준입니다. 세션을 한 번 만들어 재사용하세요 — 호출마다 모델을 로드하면 느립니다.
- 반환형 `ProductCutout`(rgba_png, mask_png 등) 계약은 유지하세요. 파이프라인과 게이트가 그걸 씁니다.
- rembg 가 사실상 빈 마스크나 전체 마스크를 내면 폴백해야 합니다. **폴백의 의미는 그대로**입니다: 누끼 실패는 `asset_mode="source"`, `fidelity_status="FALLBACK"`. 의도된 원본인 hero 는 이미 `source_original` 이며 **바꾸지 마세요.**
- 기존 추출기를 지울지 남길지는 판단하세요. 남긴다면 쓰이지 않는 코드가 되지 않게 이유가 있어야 합니다.

## 2. 라벨에서 '참고용' 제거

`source_photos.py` 에 생성 사진 라벨 `"AI 생성 활용 장면(참고용)"`, `"AI 생성 디테일(참고용)"` 이 있습니다. `(참고용)` 을 빼서 `"AI 생성 활용 장면"`, `"AI 생성 디테일"` 로 바꾸세요. `label` 필드 자체와 `product_generated` 플래그는 유지합니다 — BE 는 이 플래그로 생성물을 구분합니다.
