## 커밋 1 — variant 고정 배정 해제

대상: `assets/references/detail-page-layouts.json`, `src/detail_page_ai/validation.py`,
`tests/test_layout_catalog.py`, `tests/test_validation.py`

내용: `validation.py` 가 블록별 variant 를 고정 배정하던 것(hero·closing→paper,
detail_split→dark, usage_scene→full-bleed, notice→dark)을 걷어내고, 카탈로그의 각 원형이
블록별 variant 를 갖도록 했다. 어떤 상품이든 detail_split 이 항상 어두웠던 문제를 푼 것이다.
`photo_id` 보정은 자산 연결이라 성격이 달라 그대로 두었다.

## 커밋 2 — 비어 있던 variant 4종 CSS 구현

대상: `web/detail_page.css`

내용: DTO 에 선언돼 있으나 CSS 규칙이 0개였던 `sand`·`image-left`·`image-right`·`compact` 를
구현했다. 모델이 그 값을 내도 화면이 바뀌지 않던 상태였다. 두 워커가 독립으로 만든 안을
대조해 병합했고, 색은 새로 지어내지 않고 `reference_guide` 토큰에서 `color-mix` 로 파생시켰다.
좌우 반전은 `split-section`·`usage-section`·`palette-section` 세 곳 모두에 적용된다.
