## 배경 (실측 확인 완료)

- `src/detail_page_ai/source_photos.py:793`, `:834` 가 생성 이미지에 label="AI 생성 활용 장면(참고용)", label="AI 생성 디테일(참고용)" 을 붙입니다. `result_summary.json` 에는 케이스당 5회 '참고용'이 남습니다.

- 이것은 릴리스 차단 조건입니다(가이드 4절 5항).

## 만들 것

`scripts/check_reference_label.py` 한 파일. 파일럿 디렉터리 경로를 인자로 받아 케이스별로 판정하고, 다른 게이트 스크립트들과 같은 형식의 마크다운 표 + 요약 + 최종 판정 + 종료 코드를 냅니다. 기존 `scripts/check_cutout_fidelity.py` 와 `scripts/check_plan_diversity.py` 의 출력 형식과 종료 코드 관례를 따르세요.

판정 규칙:

1. `result_summary.json` 에서 `product_generated` 가 true 인 사진을 그 케이스의 대상 집합으로 잡습니다. 대상이 0장인 케이스(예: `--image-provider none` 실행)는 실패가 아니라 `해당 없음` 으로 분류하고 요약에 따로 세세요.
2. 대상 사진마다, 그 사진의 `label` 문자열이 `react_document.json` 안에 실제로 실려 있는지 확인합니다. 단순히 파일 전체에 '참고용' 이 몇 번 나오는지 세는 방식은 쓰지 마세요. 어느 사진에 대한 라벨인지 대응이 되어야 합니다.
3. 렌더 산출물(`detail_page.png` 가 아니라 HTML 이 남아 있다면 그 HTML, 없으면 그 항목은 `확인 불가` 로 표시)에도 라벨이 있는지 확인합니다. HTML 이 파일럿 산출물에 없으면 이 항목 때문에 전체를 FAIL 로 만들지 말고, 어떤 근거로 확인 불가인지 출력에 남기세요.
4. 원본 유래 컷(`product_generated=false`)에 라벨이 붙어 있으면 **그것도 실패**입니다. 원본 사진을 AI 생성물로 오인시키는 것이기 때문입니다. 이 케이스를 별도 항목으로 세세요.
5. 전 케이스가 조건을 만족하면 종료 코드 0, 하나라도 어기면 1.
