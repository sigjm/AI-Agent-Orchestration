## 지시

## 이 작업의 성격

**교차검증이다.** 다른 워커 한 명이 같은 브리프로 독립 작업 중이다.
상대의 결과 파일이나 `.orchestration/tasks/` 의 다른 브리프를 열지 마라.
상대와 결론을 맞추려 하지 말고, 네 판단으로 만들어라.

## 문제

상세페이지의 시각적 다양성이 부족하다. 원인을 추적한 결과 **DTO 에 선언된 variant 8종 중
절반이 CSS 규칙이 0개**다.

| variant | DTO | `web/detail_page.css` 규칙 수 |
|---|---|---|
| paper | 있음 | 5 |
| light | 있음 | 5 |
| dark | 있음 | 9 |
| full-bleed | 있음 | 9 |
| **sand** | 있음 | **0** |
| **image-left** | 있음 | **0** |
| **image-right** | 있음 | **0** |
| **compact** | 있음 | **0** |

모델이 `image-left` 를 내도 화면은 안 바뀐다. 좌우 반전, 여백 축소, 색면이 전부 죽어 있다.

## 작업

`web/detail_page.css` 에 비어 있는 네 variant 의 규칙을 구현한다.

- `.block--sand` — 따뜻한 색면 배경. 기존 `paper`/`light`/`dark` 와 **명확히 구별되는 톤**이어야
  한다. 프로젝트 색 체계는 `src/detail_page_ai/reference_guide.py` 의 `REFERENCE_GUIDE_COLORS`
  에 있다. 거기 정의된 값을 쓰고 새 색을 지어내지 마라.
- `.block--image-left` / `.block--image-right` — 이미지와 텍스트의 좌우 배치를 뒤집는다.
  기존 `detail_split` 계열 레이아웃이 어떻게 조판되는지 먼저 읽고, 그 구조 위에서 방향만
  바꾸는 최소 규칙으로 만들어라.
- `.block--compact` — 여백과 타이포 스케일을 줄여 밀도 높은 섹션을 만든다.
  섹션이 연속될 때 리듬 변화를 주는 용도다.

**렌더러가 variant 를 어떤 클래스로 내보내는지 먼저 확인하라** (`src/detail_page_ai/html_renderer.py`).
클래스 이름이 `block--{variant}` 가 맞는지 코드로 확인하고 시작하라. 추측하지 마라.

## 지켜야 할 것

- **기존 4종(`paper`·`light`·`dark`·`full-bleed`) 규칙을 바꾸지 마라.** 추가만 한다.
  기존 페이지 렌더가 달라지면 회귀다.
- 반응형을 깨뜨리지 마라. 캔버스 폭은 774px 고정이고 Playwright 로 PNG 를 렌더한다.
- `reference_guide.py` 의 타이포 스케일(hero 40/700/1.25, 섹션 제목 30/700/1.35,
  카드 제목 19/600/1.4, 본문 16/400/1.7, 라벨 13/500/1.5)과 어긋나지 않게 하라.
- 다크 모드 대응은 불필요하다. 이 CSS 는 상세페이지 PNG 렌더용이지 뷰어용이 아니다.

### 2. 구현 내용 및 선택 근거 (공예 테이블웨어 실사용 맥락 반영)
1. **`(1) image-left + dark` (비대칭 비율, 좌측 이미지 스택, 우측 세리프+넘버링)**
   - **비대칭 비율 조판**: 5:5 대신 이미지가 좁고 텍스트가 넓은 비대칭 비율(`grid-template-columns: 310px 1fr;` — 약 40%:60%) 적용.
   - **좌측 미디어 스택**: `order: 1` 강제 및 `display: flex; flex-direction: column; gap: 8px;`로 접사 컷들을 세로로 안정감 있게 적재.
   - **우측 어두운 색면 + 세리프 + 넘버링**:
     - 배경: `var(--espresso)` (`#121B29`), 패딩 44px 40px
     - 제목: 세리프 서체(`font-family: "Noto Serif KR", "Batang", serif; font-size: 26px; color: #F8EFE4;`)
     - 넘버링 설명 목록: CSS 카운터(`decimal-leading-zero`)를 활용하여 `01`, `02` 형태의 브론즈 악센트 넘버링과 `color: #D5C3B2` 본문 설명 조판.
   - **`image-right` 대칭 지원**: 카피 60% 좌측(`order: 1`), 미디어 40% 우측(`order: 2`), 배경 `#EAE1D6` 지원.

2. **`(2) full-bleed + 텍스트 오버레이` (전면 사진 위 중앙 흰 세리프 문구)**
   - 전면 이미지 위에 어두운 스크림(`rgba(18, 27, 41, 0.48)`)을 오버레이하고, 카피 박스를 상하·좌우 중앙(`align-self: center; justify-self: center; text-align: center;`)에 정렬.
   - 제목: 흰색 세리프(`font-family: "Noto Serif KR", "Batang", serif; font-size: 32px; color: #FFFFFF; text-shadow: 0 2px 10px rgba(0,0,0,0.5);`).
   - 본문/아이브로우: 흰색 고대비 텍스트(`color: rgba(255,255,255,0.92)` / `text-shadow: 0 1px 6px rgba(0,0,0,0.45)`).

3. **`(3) sand` (마무리 섹션의 따뜻한 색면 배경 + 중앙 정렬 카피)**
   - **마무리 섹션 (`closing-section.block--sand`)**:
     - 배경색: `#EAE1D6` (따뜻한 모래/도자 질감의 색면).
     - 레이아웃: `text-align: center;`, 최대 너비 480px의 본문 문단 중앙 배치, `color: var(--ink)` 제목 및 `var(--cool-grey-500)` 본문.
   - **기타 섹션 호환**: `intro-band`, `split-section`, `palette-section`, `usage-section`, `feature-grid`에도 동일하게 따뜻한 모래색 톤 통일.

4. **`(4) compact` (품목명/소재/컬러/사이즈 2x2 촘촘한 정보 블록)**
   - **`info-section` 2x2 그리드화**:
     - `tbody`를 `display: grid; grid-template-columns: 1fr 1fr; gap: 8px 24px;`로 변환하여 4개 명세 항목(품목명, 소재, 컬러, 사이즈)이 2x2 형태로 촘촘하게 배치되도록 구현.
     - 각 행(`tr`)은 `display: flex;`로 라벨(`th`, 폭 자동, `color: var(--bronze)`)과 값(`td`)을 가로 한 줄에 배치.
   - **밀도 및 타이포그래피 스케일 축소**:
     - 섹션 상단 마진: 72~76px → 32px
     - 패딩 축소: `feature-card`(높이 120px, 패딩 16px 18px), `split-section`(높이 260px), `usage-section__media`(높이 200px)
