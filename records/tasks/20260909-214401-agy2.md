## 배경

평가 파일럿에서 **자동 지표가 전부 통과했는데 실제 산출물이 망가진** 사례가 나왔다.

hero 컷아웃이 제품을 지워버려 ceramic 은 원본의 3%, textile 은 26% 만 남았는데,
`docs/evaluation/metrics-definition.md` 의 자동 gate 는 6건 전부 PASS 였다. React schema
validity, React tree safety, alias serialization, image reference resolution, 원본 SHA-256
일치, 합성 fidelity 전부 통과했다. **합성 fidelity 검증이 "선언된 변환이 그대로 적용됐는가"
만 보기 때문에, 마스크가 제품을 지워도 통과한다.**

같은 파일럿에서 금·보석 목걸이가 금속 제품용 씬 분기로 배정되는 오분류도 나왔는데,
이것도 잡아내는 지표가 없었다.

두 구멍을 메우는 도구가 이미 추가됐다.
- `scripts/check_cutout_fidelity.py` — 원본 대비 비배경 픽셀 보존율을 측정한다.
  판정은 0.6 초과 OK, 0.25 미만 심각 손실, 그 사이 부분 손실. 심각 손실이 있으면 종료 코드 1.
- `scripts/check_scene_direction_coverage.py` — 제품 유형별 씬 분기 배정이 기대와 맞는지
  판정한다. 오분류나 기본값 사용이 있으면 종료 코드 1.

## 작업

`docs/evaluation/metrics-definition.md` **한 파일만** 수정한다.

1. **"2. 지표 정의" 표에 지표 두 개를 추가한다.**
   - 컷아웃 원본 보존율: 분자/분모와 목표치를 기존 표의 서술 방식에 맞춰 쓴다.
     측정 도구가 `scripts/check_cutout_fidelity.py` 임을 밝힌다.
   - 씬 분기 적합률: 기대 분기와 일치한 케이스 / 판정한 케이스.
     측정 도구가 `scripts/check_scene_direction_coverage.py` 임을 밝힌다.
   목표치는 네가 임의로 정하지 말고, 위에 적힌 판정 임계값(0.6 / 0.25)과 "오분류 0건" 을
   근거로 서술하라.

2. **합성 fidelity 지표의 한계를 명시한다.**
   기존 "합성 fidelity" 행 근처에, 이 지표가 마스크 품질을 보지 않으며 컷아웃 보존율과
   함께 봐야 한다는 점을 한두 문장으로 적는다. 기존 행의 정의 자체는 바꾸지 마라.

3. 문서 상단의 상태 문구가 "초안 / 2026-09-08 갱신" 이고 "실제 일괄 실행 0" 이라고
   되어 있다. **파일럿 6건이 실제로 실행됐으므로** 그 사실을 반영하되,
   60건 전체 평가는 아직 실행되지 않았다는 점을 흐리지 마라.
   자세한 실행 기록은 `docs/evaluation/pilot-report-2026-09-09.md` 에 있으니 링크로 연결한다.
