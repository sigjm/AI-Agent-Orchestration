## 지시

## 문제

구조 점검에서 나온 결함이다. 두 패키지가 서로를 import 한다.

- `src/local_detail_page_ai/*.py` -> `detail_page_ai` import 29회 (정상 방향)
- `src/detail_page_ai/app.py:43-49` -> `local_detail_page_ai.adapters`, `.clients`, `.runner` import (역방향)

결과적으로 **`detail_page_ai` 패키지가 `local_detail_page_ai` 없이는 import 되지 않는다.**
`detail_page_ai` 는 도메인·파이프라인 계층이고 `local_detail_page_ai` 는 로컬 MLX 실행
어댑터다. 어댑터를 갈아끼우거나 도메인만 떼어 쓰려면 이 방향이 끊겨야 한다.

## 목표

`detail_page_ai` 의 어떤 모듈도 **모듈 수준에서** `local_detail_page_ai` 를 import 하지 않게 한다.

방법은 네가 정하라. 예를 들어 조립(wiring) 책임을 `local_detail_page_ai` 쪽 팩토리로 옮기거나,
별도 조립 모듈을 두거나, `app.py` 안에서 지연 import 로 경계를 명확히 하는 방법이 있다.
**다만 지연 import 로 숨기는 것은 최후 수단으로 본다.** 방향 자체를 바로잡는 쪽을 우선하라.
어떤 방법을 왜 골랐는지 결과 보고에 적어라.

## 반드시 지킬 것 (외부 계약)

- `pyproject.toml` 의 진입점 `serve-ai = "detail_page_ai.app:run"` 은 **계속 동작해야 한다.**
  진입점 경로를 바꿔야 한다면 `pyproject.toml` 도 함께 고치고, README 의 `serve-ai` 사용
  설명이 여전히 맞는지 확인하라.
- 기존 공개 함수·클래스 이름을 바꾸지 마라. 이동은 되지만 호출부가 전부 따라와야 한다.
- FastAPI 앱 생성과 라우팅 동작은 그대로여야 한다.

## 구조 테스트 추가 (이번 작업의 핵심 산출물)

`tests/test_project_layout.py` 에 **의존 방향을 강제하는 테스트**를 추가하라.
이 저장소는 이미 구조 규약을 문서가 아니라 테스트로 박아 두는 방식을 쓰고 있으니 그 방식을 따른다.

- `src/detail_page_ai/**/*.py` 를 AST 로 파싱해서, 모듈 수준 `import` / `from ... import` 중
  `local_detail_page_ai` 를 참조하는 것이 하나도 없어야 한다.
- 위반 시 어느 파일 몇 번째 줄인지 실패 메시지에 나오게 하라.
- 함수 내부의 지연 import 까지 금지할지는 네 판단이되, 판단 근거를 테스트 주석에 남겨라.

## 결과

### 변경 파일

- `src/local_detail_page_ai/factory.py`
  - 기존 `detail_page_ai.app.build_service()`에 있던 로컬 MLX/Ollama 클라이언트, 분석기, 이미지 생성기, 저장소와 서비스 조립 책임을 로컬 어댑터 패키지로 이동했다.
  - core 계층(`detail_page_ai`)을 import하는 방향은 유지하고, 로컬 패키지가 역방향 의존을 만들지 않도록 했다.
- `src/detail_page_ai/app.py`
  - 모듈 수준의 `local_detail_page_ai` import를 제거했다.
  - 기존 공개 함수 `build_service()`와 `serve-ai = "detail_page_ai.app:run"` 계약은 유지하고, 함수 내부에서 로컬 factory로 위임하는 호환 경계만 남겼다. 실제 조립 로직은 factory에 있다.
- `tests/test_project_layout.py`
  - `src/detail_page_ai/**/*.py`를 AST로 검사해 모듈 수준 `local_detail_page_ai` import가 있으면 파일·줄 번호와 함께 실패하도록 구조 테스트를 추가했다.
  - 함수 내부 지연 import는 실행 조립 경계의 호환성을 위해 허용한다는 판단을 테스트 주석에 남겼다.
- `tests/test_app.py`
  - 조립 구현이 이동한 `local_detail_page_ai.factory`를 대상으로 기존 fake client/renderer 주입 테스트를 유지하도록 patch 지점을 갱신했다.
