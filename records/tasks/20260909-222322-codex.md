## 지시

## 문제

네가 방금 한 `scripts/` 재조직은 대부분 정확했다. `git mv` 로 이력을 보존했고, `html_renderer.py`
와 `package.json` 의 참조도 새 경로로 따라갔다. 다만 **테스트 1건이 깨진 상태로 남았다.**

```
FAILED tests/test_project_layout.py::test_legacy_flat_script_locations_are_removed
AssertionError: legacy flat script locations remain: ['scripts/render_detail_page.mjs']
```

원인은 자기모순이다. 하위 호환용 심볼릭 링크를 남겼는데,

```
scripts/render_detail_page.mjs -> runtime/render_detail_page.mjs
```

같은 커밋에서 추가한 테스트가 **그 경로가 없어야 한다**고 단언한다. 둘 중 하나는 틀렸다.

현재 전체 테스트는 `1 failed, 257 passed` 다.

## 작업

둘 중 하나를 골라 일관되게 만들어라. **판단은 네가 하되 근거를 결과 보고에 적어라.**

- (a) 심볼릭 링크를 제거한다. 재조직의 목적이 평면 구조 해소였고 참조는 이미 전부 새 경로로
  옮겼으므로, 호환 링크가 남을 이유가 없다면 이쪽이 깔끔하다.
- (b) 링크를 의도적으로 유지해야 할 이유가 있다면 테스트를 그 의도에 맞게 고친다.
  단 "테스트를 통과시키려고 검사를 지우는" 식은 안 된다. 링크가 필요한 이유가 있어야 한다.

링크를 제거하는 쪽을 고른다면, 제거 전에 `grep -rn "scripts/render_detail_page.mjs"` 로
남은 참조가 없는지 확인하라.

## 결과

### 선택 및 변경

- (a) 심볼릭 링크 제거를 선택했다.
- 제거 전 `grep -rn "scripts/render_detail_page.mjs"`를 실행했고 운영 참조가 없음을 확인했다.
- `scripts/render_detail_page.mjs -> runtime/render_detail_page.mjs` 호환용 심볼릭 링크만 제거했다.
- 재조직의 목적이 평면 구조 해소이고 README·docs·package.json·스크립트 참조가 이미 `scripts/runtime/render_detail_page.mjs`로 정리되어 있어 링크를 유지할 이유가 없었다. 링크를 남기면 레거시 경로 검사가 구조 목적과 모순된다.

### 검증

- `.venv/bin/python -m pytest -q tests/test_project_layout.py::test_legacy_flat_script_locations_are_removed` → **1 passed**
- `.venv/bin/python -m pytest -q` → **258 passed in 7.70s**
- 제거 후 레거시 경로 존재 검사 → `scripts/render_detail_page.mjs` 없음
- 제거 후 `grep -rn "scripts/render_detail_page.mjs" .` → 운영 참조 없음
- `git status --short scripts/` → 의도한 `git mv` rename 항목과 기존 `scripts/orchestration/workers.tsv` 변경만 확인
- `git diff --check` → 통과
- 평가 스크립트 4종은 이번에도 최상위에 그대로 두었으며 이동하지 않았다.

### 미해결 이슈

없음. `scripts/render_detail_page.mjs` 레거시 심볼릭 링크가 제거되어 테스트와 디렉터리 구조가 일관되게 정리됐다. 기존 워커가 수정 중인 `scripts/orchestration/workers.tsv`는 다른 작업의 변경이므로 보존했다.
