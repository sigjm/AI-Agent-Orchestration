## 요구
1. `GET /health` — 인증 없이 접근 가능해야 합니다(`AI_INTERNAL_AUTH_TOKEN` 검사 대상이 아님). probe 가 토큰을 들고 오지 않습니다. 앱이 요청을 받을 수 있으면 200, 본문은 최소한(`{"status":"ok"}` 정도).
   - 현재 `app.py` 의 다른 라우트가 인증을 어떻게 거는지 확인하고(`_require_internal_auth` 등), `/health` 가 그 경로를 타지 않게 하세요.
   - **모델 서버 호출을 넣지 마세요.** liveness probe 가 추론 서버 상태에 묶이면 추론 서버가 느릴 때 파드가 재시작됩니다.
2. `GET /health/ready` — readiness 용으로 분리해 추가하세요. 설정된 추론 서버(`LOCAL_TEXT_URL`, 그리고 이미지 provider 가 none 이 아니면 `LOCAL_IMAGE_URL`)의 `/v1/models` 를 **짧은 타임아웃(2초 내외)** 으로 확인해 전부 응답하면 200, 아니면 503. 실패해도 예외를 밖으로 던지지 말고 503 과 간단한 사유를 돌려주세요. provider 가 `none` 이면 그 대상은 확인하지 않습니다.
   - 확인 방식은 기존 클라이언트 코드를 재사용하지 말고 간단한 HTTP GET 으로 하세요(클라이언트는 생성/편집 전용입니다).
3. 기존 라우트·인증·응답 스키마는 바꾸지 마세요.
