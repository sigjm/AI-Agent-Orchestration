## 실행 순서

1. 서버 확인:
   `.venv/bin/python -c "import json,urllib.request; print([m['id'] for m in json.load(urllib.request.urlopen('http://127.0.0.1:11234/v1/models',timeout=5))['data']])"`
   `ddalcu/Qwen3.8-27B-MLX-Serve-4bit` 와 `mlx-community/flux2-klein-9b-4bit` 가 있어야 한다.
   없으면 중단하고 보고하라. **서버를 네가 띄우거나 끄지 마라.**

2. 재생성:
   ```
   nohup .venv/bin/python scripts/run_eval_pilot.py --text-timeout 900 --image-timeout 900 \
     > /tmp/pilot_rerun.log 2>&1 &
   ```
   **건당 4~6분, 전체 30분 이상 걸린다.** 위처럼 백그라운드로 돌리고 주기적으로
   `tail /tmp/pilot_rerun.log` 와 새로 생긴 `generated/evaluation/pilot-<타임스탬프>/run_index.json`
   을 확인하라. 절대 중복 실행하지 마라. 기다리는 동안 다른 파일을 수정하지 마라.

3. 완료 후 게이트 두 개를 새 디렉터리에 실행하고 출력 표와 종료 코드를 기록:
   ```
   .venv/bin/python scripts/check_cutout_fidelity.py --pilot-dir <새 디렉터리>
   .venv/bin/python scripts/check_scene_direction_coverage.py --pilot-dir <새 디렉터리>
   ```
