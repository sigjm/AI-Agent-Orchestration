## 작업

### 1. `web/detail_page.css` 에 토큰을 정의한다

위 토큰을 CSS 커스텀 프로퍼티로 선언하라. 이름은 스펙의 의미 구조가 드러나게 짓되
(`--bg-default`, `--fill-jade-impact`, `--font-dark-weak` 같은 식) 네가 일관되게 정하라.
투명도가 있는 값은 `color-mix` 나 `rgb(... / 30%)` 중 적절한 방식을 쓰라.

### 2. 기존 색 사용처를 새 토큰으로 옮긴다

지금 CSS 는 `--black`, `--cool-grey-*`, `--jade-blue-*`, `--ink`, `--bronze*`, `--espresso`
같은 자체 토큰을 쓴다. **이것들을 새 의미 토큰으로 매핑하라.**

- 어떤 옛 토큰이 어떤 새 토큰에 대응하는지 **매핑 표를 결과 보고에 적어라.**
- 대응하는 새 토큰이 없는 옛 색(예: `--bronze`, `--espresso`)이 있으면 **지우지 말고
  그대로 두고, 어떤 것이 스펙 밖에 남았는지 보고하라.** 임의로 비슷한 색에 끼워 맞추지 마라.
- 8종 variant(`paper`·`light`·`sand`·`dark`·`image-left`·`image-right`·`full-bleed`·`compact`)
  규칙이 새 토큰으로 동작해야 한다. **variant 간 시각적 구별이 사라지면 안 된다** —
  특히 `sand` 는 스펙에 대응하는 따뜻한 색이 없으니 어떻게 처리했는지 보고하라.

### 3. `src/detail_page_ai/reference_guide.py` 의 `REFERENCE_GUIDE_COLORS` 를 맞춘다

이 값이 프롬프트에 실려 모델에게 색 방향을 지시한다. CSS 와 어긋나면 모델이 지시받은 색과
실제 렌더 색이 달라진다. **스펙 값으로 갱신하고, `REFERENCE_GUIDE_VERSION` 도 올려라.**
