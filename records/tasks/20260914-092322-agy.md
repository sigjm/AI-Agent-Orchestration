## 3. `docs/operations/ubuntu-deployment.md`
사람이 순서대로 따라 할 수 있게 쓰세요.
1. 서버 준비: Docker Engine·compose plugin 설치(Ubuntu 공식 절차 요지), 디스크 여유(이미지 + 모델 973MB + 산출물).
2. 코드 받기: `deploy/ubuntu` 브랜치 체크아웃.
3. `.env` 작성: `.env.example` 복사, 반드시 바꿀 값.
4. 기동: `docker compose up -d --build`, 상태 확인(`docker compose ps` healthy), 로그.
5. 첫 누끼 시 모델 다운로드가 한 번 일어나고 볼륨에 남는다는 점. 사설망이면 미리 받아 볼륨에 넣는 방법(`U2NET_HOME` 경로에 `birefnet-general.onnx`).
6. **추론 서버 — 이 문서의 핵심 제약을 정면으로 쓰세요.** 로컬 개발은 Apple Silicon 전용 MLX Serve(`127.0.0.1:11234`, Qwen3.8-27B + flux2-klein-9b)를 씁니다. Ubuntu 에서는 MLX Serve 가 돌지 않습니다. 선택지:
   - (a) 추론은 기존 Mac 의 MLX Serve 에 두고 Ubuntu 서비스가 네트워크로 호출(`LOCAL_TEXT_URL`, `LOCAL_IMAGE_URL` 을 Mac 주소로). Mac 쪽 `--host` 를 외부 바인딩으로 띄워야 함.
   - (b) Ubuntu GPU 서버에서 OpenAI 호환 텍스트 서버(vLLM 등). 텍스트 분석 요청 형식은 `src/local_detail_page_ai/clients.py` 의 `MlxServeChatClient` 를 읽고 호환 조건을 적으세요. **이미지 생성은 MLX Serve 전용 JSON 편집 규약(`POST /v1/images/generations`, `mode: "edit"`)을 쓰므로 일반 서버로 대체되지 않습니다** — `clients.py` 를 읽고 근거와 함께 쓰세요. 이 경우 `LOCAL_IMAGE_PROVIDER=none` 으로 두면 AI 생성 컷 없이 원본·누끼 컷만으로 생성된다는 점.
   어느 쪽이 맞는지는 서버 사양에 달려 있으니 **결정 필요**로 표시하세요. 검증하지 않은 성능·비용 수치는 쓰지 마세요.
7. 동작 확인: 컨테이너 헬스, 그리고 실제 한 건 생성 요청 방법(API 경로는 `src/detail_page_ai/app.py` 를 읽고 실제 경로로).
8. 업데이트·중지·백업(볼륨 안 `state.sqlite3`).

### 4. 추론 서버 절 요지 (`docs/operations/ubuntu-deployment.md` §6)
- **핵심 제약**: 로컬 개발 환경은 Apple Silicon 통합 메모리 전용 MLX Serve(`Qwen3.8-27B` + `flux2-klein-9b`)를 사용하므로, Ubuntu(x86_64)에서는 MLX Serve 바이너리 실행이 원천 불가능합니다.
- **선택지 (a) — Mac 호스트 MLX 원격 호출**:
  - Mac 호스트에서 `--host 0.0.0.0`으로 바인딩하여 실행하고, Ubuntu `.env`의 `LOCAL_TEXT_URL`, `LOCAL_IMAGE_URL`에 Mac IP를 지정.
  - Flux2 기반의 고품질 연출 컷 생성을 코드 수정 없이 100% 그대로 활용 가능하나, Mac 장비가 상시 가동되어야 함.
- **선택지 (b) — Ubuntu 텍스트 서버 호스팅 + 이미지 생성 비활성화 (`LOCAL_IMAGE_PROVIDER=none`)**:
  - **텍스트 분석**: `MlxServeChatClient`는 표준 OpenAI `/v1/chat/completions` 포맷(multimodal `image_url` + `json_object`)을 요구하므로 vLLM이나 Ollama로 대체 가능.
  - **이미지 생성 대체 불가의 근거**: `MlxServeImageClient.edit()`은 표준 multipart `/v1/images/edits`가 아닌 `POST /v1/images/generations`에 `mode: "edit"`, `image: "<base64>"`를 담아 보내는 **MLX Serve 전용 비표준 JSON 편집 규약**(`clients.py:230-245`)을 쓰므로, 시중의 일반 이미지 서빙 프레임워크로는 직접 대체가 불가능함.
  - 따라서 Ubuntu 단독 구성 시 `LOCAL_IMAGE_PROVIDER=none`, `BACKGROUND_PROVIDER=none`으로 설정하며, 이 경우 AI 생성 컷을 건너뛰고 원본 사진과 rembg 누끼 컷만으로 완성형 상세페이지를 정상 생성함.
- **결정 필요**: 운영팀의 인프라(Ubuntu 서버 GPU 보유 여부 및 Mac 연동 가능 여부)에 따라 [선택지 A] 또는 [선택지 B] 중 결정 필요.
