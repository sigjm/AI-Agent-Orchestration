`scripts/run_eval_pilot.py`, `scripts/build_review_sheet.py`, `scripts/check_cutout_fidelity.py`,

이 도구들은 평가 게이트로 쓸 것이라 `src/` 만큼 신뢰성이 필요하다.

## 작업 1 — 테스트 추가

`tests/test_eval_scripts.py` **한 파일**을 새로 만든다. 네 스크립트를 import 해서
**모델 호출 없이** 검증 가능한 부분만 테스트한다.

최소한 다음을 덮어라.

- `run_eval_pilot.select_pilot_cases()`: 실제 데이터셋으로 6건이 선정되고, 카테고리가 6개
  모두 다르며, **두 번 호출해도 같은 결과**(결정적 선정)인지.
- `build_review_sheet`: CSV 헤더에 4축 × 검수자 2인 + 합의 열이 있고, **점수 열이 비어 있는지**.
  실패한 case 도 행으로 남는지.
- `check_cutout_fidelity`: 보존율 계산 함수가 알려진 입력에서 기대값을 내는지
  (PIL 로 단색/부분 이미지를 만들어 넣으면 된다), 판정 경계(OK / 부분 손실 / 심각 손실)가
  임계값대로 갈리는지.
- `check_scene_direction_coverage`: 기대 분기 대응표가 6개 카테고리를 모두 덮는지,
  오분류가 있을 때 실패로 판정되는지.

주의할 점:
- **모델 서버를 호출하는 코드 경로를 실행하지 마라.** `run_eval_pilot` 의 실제 실행 함수는
  호출하지 말고 선정 로직만 테스트한다.
- `generated/` 아래에 파일을 쓰지 마라. 임시 출력이 필요하면 pytest 의 `tmp_path` 를 써라.
- 테스트가 특정 파일럿 실행 디렉터리 이름(`pilot-20260909-191344`)에 의존하지 않게 하라.
  그 디렉터리는 나중에 재생성으로 대체된다. 필요하면 `tmp_path` 에 최소 fixture 를 만들어라.
