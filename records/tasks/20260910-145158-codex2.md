## ④ 추론 API 에 반영할 것

- **이미지 편집 경로가 바뀌었다.** `src/local_detail_page_ai/clients.py` 의 `edit()` 이
  multipart `/v1/images/edits` 대신 JSON `/v1/images/generations` 의 `mode:"edit"` 을 쓴다.
  참조 이미지를 base64 로 싣고 `steps` 는 정수로 보낸다. 이유는 MLX Core 26.9.1 의 multipart
  경로가 내부 변환 과정에서 `steps`·`strength` 를 전달하지 않기 때문이다. 문서에 이 경위가
  이미 적혀 있다면 그대로 두고, 없으면 보강하라. **다음 사람이 되돌리지 않도록 이유가 남아야 한다.**
- `steps` 기본값이 12에서 **4** 로 바뀌었다. Flux2 Klein 이 4스텝 증류 모델이고 지금까지의
  모든 실측이 그 값 기준이다.
- **`strength` 는 지원되지 않는다.** FLUX.2 in-context edit 모드가 사용하지 않는다.
  문서가 이 파라미터를 조절 가능한 것으로 서술하고 있으면 고쳐라.
- 분석 프롬프트 생성에 인자가 추가됐다. `build_analysis_prompt` 가 레이아웃 원형을 받고,
  `src/local_detail_page_ai/adapters.py` 가 원본 이미지 SHA-256 을 시드로 원형을 결정한다.
  `ProductAnalyzer` 프로토콜 시그니처는 바뀌지 않았다.

## ⑤ BE/FE 명세에서 확인할 것

- **`page_plan` 의 `variant` 값이 이제 모델·원형이 정한다.** 이전에는 코드가 블록별로
  고정 배정했다(detail_split→dark 등). 명세가 그 고정을 전제로 서술하고 있으면 고쳐라.
  허용 값은 DTO 의 8종: `paper`, `light`, `sand`, `dark`, `image-left`, `image-right`,
  `full-bleed`, `compact`.
- **`page_plan` 블록 수 범위**가 바뀌었다. 프롬프트 계약을 확인해 실제 값을 반영하라.
- 엔드포인트·DTO·상태 전이는 이번에 바뀌지 않았다. **바뀌지 않은 것을 바꾸지 마라.**
  다만 코드와 대조해 이전부터 어긋나 있던 서술이 있으면 고쳐라.
