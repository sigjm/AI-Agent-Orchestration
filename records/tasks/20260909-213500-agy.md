## 지시

## 배경

네가 만든 `scripts/check_scene_direction_coverage.py` 는 정상 동작한다. 목걸이(cma-109609)가
`metal` 분기로 가는 오분류를 표에서 정확히 짚어냈다. 확인했다.

그런데 **종료 코드가 0으로 나온다.** 내가 준 브리프에 "기본값(default)으로 떨어진 건이
있으면 종료 코드 1" 이라고만 써서 그렇다. 이번 사례는 기본값이 아니라 오분류라 조건에
안 걸린다. 브리프의 판정 기준이 좁았던 것이니 네 잘못이 아니다.

문제는 이 도구를 **수정 전후 회귀 게이트**로 쓸 거라는 점이다. 오분류를 발견하고도 0을
반환하면 게이트 역할을 못 한다.

## 작업

`scripts/check_scene_direction_coverage.py` 를 다음과 같이 보완한다.

1. **기대 분기(expected branch)를 카테고리별로 정의한다.**
   평가 데이터셋 `cma_real_v1` 의 6개 카테고리에 대해 어느 분기가 맞는지 명시한다:
   textile -> textile, box -> box, ceramic -> ceramic, metalware -> metal,
   furniture -> wood, jewelry -> **jewelry 분기** (지금은 존재하지 않는다. 다른 워커가
   추가하는 중이다. 아직 없으면 "미구현" 으로 표시하고 실패로 집계한다.)
   이 대응표는 파일 상단에 상수로 두고 주석으로 근거를 남겨라.

2. **종료 코드 규칙을 다음으로 바꾼다.**
   - 기대 분기와 다른 분기에 떨어진 케이스가 하나라도 있으면 종료 코드 1 (오분류)
   - 기본값(default)으로 떨어진 케이스가 하나라도 있으면 종료 코드 1 (미대응)
   - 전건이 기대 분기와 일치하면 0
   출력에 케이스별로 `기대 / 실제 / 판정` 을 나란히 보여라.

3. `--strict-off` 같은 플래그로 기존처럼 "기본값만 실패" 로 완화할 수 있게 두는 것은
   선택이다. 필요 없다고 판단하면 넣지 마라.
