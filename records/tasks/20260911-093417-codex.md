# 컷아웃 추출기 수정 — 폴백률 85% 해소

- 워커: codex
- 발행: 2026-09-11 09:34:17
- 지휘: Claude Code (오케스트레이터 세션)

## 지시

컷아웃 추출기가 실제 사진 대부분에서 동작하지 않는 문제를 수정합니다.

## 확인된 사실

`generated/evaluation/full60-20260910-204433` 60건 중 **51건(85%)이 컷아웃 미수행**입니다. `fidelity_status=FALLBACK`, `asset_mode=source` 로 원본이 그대로 나갔고 배경이 전혀 제거되지 않았습니다. 파일럿에서도 6건 중 4건이 그랬는데 게이트가 보존율 100%를 찍어주는 바람에 9차수 내내 "컷아웃 6/6 OK"로 보고됐습니다.

관리자가 `SolidBackgroundCutoutExtractor` 의 거부 지점을 계측한 결과입니다.

| 거부 조건 | 건수 |
| --- | --- |
| **1. 모서리 배경색 불균일** (`src/detail_page_ai/source_photos.py:118-120`) | **50건** |
| 4. 최대 성분비 미달 (`:150-153`) | 1건 (0.495, 임계값 0.50 바로 아래) |
| 통과 | 9건 |

즉 **파편화 가드가 아니라 첫 관문에서 50건이 걸립니다.** 마스크를 만들어 보지도 못하고 끝납니다.

해당 코드는 네 모서리를 뽑아 평균을 배경색으로 삼고, 한 모서리라도 그 평균에서 RGB 거리 `corner_uniformity_tolerance=24.0` 을 넘으면 `None` 을 반환합니다.

60건의 모서리 최대 편차 분포입니다.

```
최소 6.4 / 중앙값 101.3 / 최대 194.0
허용치  24 → 통과 10/60      허용치  50 → 통과 24/60
허용치  40 → 통과 20/60      허용치 100 → 통과 30/60
허용치 150 → 통과 55/60
통과 9건의 편차: 6.4 6.4 6.4 8.1 11.0 11.7 13.3 13.3 20.2 20.2
바로 위 10건  : 24.3 26.0 29.2 30.6 30.6 32.3 32.9 34.6 35.4 39.9
```

중앙값이 101인데 임계값이 24입니다. 미술관 사진은 부드러운 비네팅이나 그라데이션 배경을 쓰기 때문에 네 모서리가 같은 값일 수 없습니다. **"모서리 네 개가 거의 같은 색"이라는 전제 자체가 이 데이터셋에 맞지 않습니다.**

## 요구사항

1. **폴백률을 실질적으로 낮추세요.** 다만 목표는 "숫자를 올리는 것"이 아닙니다. 배경을 안전하게 식별할 수 있는 사진에서 컷아웃이 수행되게 하는 것입니다.
2. **임계값만 올려서 해결하지 마세요.** 허용치를 150으로 키우면 55건이 통과하지만, 그건 배경이 균일하다는 근거 없이 통과시키는 것입니다. 그라데이션 배경을 다루려면 단일 배경색 가정 자체를 손봐야 합니다. 예를 들어 모서리 평균 한 점이 아니라 테두리 픽셀 분포로 배경을 모델링하는 방향이 있습니다. 방식은 당신이 판단하세요.
3. **침식이 돌아오면 실패입니다.** 이 가드들은 밝은 제품이 배경으로 지워지는 결함을 막으려고 이 세션에서 넣은 것입니다. 완화하면 그 결함이 되살아납니다. 폴백률과 침식률은 트레이드오프이며 **양쪽을 동시에 측정하면서** 조정해야 합니다.
4. 최대 성분비 0.50 에 0.495 로 걸린 1건도 확인하세요. 경계에 붙어 있다는 것은 그 값의 근거가 약하다는 신호일 수 있습니다.
5. 고른 값마다 **근거를 코드 주석에 남기세요.** 분리 구간을 데이터로 제시하지 못하면 그 값을 고르지 마세요.

## 측정 수단

보강된 게이트가 자입니다. `scripts/check_cutout_fidelity.py` 가 이제 '손실'과 '미수행'을 분리하고 배경 잔존을 탐지하며 요약에 컷아웃 수행률을 냅니다. 현재 기준선은 이렇습니다.

```
요약: 총 60건 | OK: 3건 | 부분 손실: 4건 | 심각 손실: 0건
      컷아웃 수행: 9/60건 (15.0%) | 컷아웃 미수행: 51건 | 배경 잔존: 2건
```

정답 집합은 `docs/evaluation/cutout-ground-truth.md` 에 있습니다. 침식 4건(`165266` `165267` `165271` `122443`), 폐곡선 잔존 2건(`159023` `131719`)입니다. **이 4건의 침식이 수정 후에도 침식으로 남으면 안 됩니다** — 수정의 목표 중 하나입니다.

### 변경

- `src/detail_page_ai/source_photos.py`
  - 네 모서리 평균 및 `corner_uniformity_tolerance` 사전 거부를 제거하고, 전체 프레임 경계 픽셀을 1차원 중앙값 평활한 뒤 저해상도 조화 보간한 공간 배경장으로 연결 배경을 판정하도록 변경했다.
  - 밝은 중성 비네트에는 수직/수평 경계 보간과 조화장 중 밝은 추정을 사용하되, 세 추정이 모두 중성일 때만 적용한다. 따라서 유색 배경/제품에는 이 보정이 적용되지 않는다.
  - 기본 색 일치 허용치는 `28 → 36`으로 보정했다. 이는 16px 공간장 보간의 8-point 오차 예산을 포함한 값이며, 단일 배경색 통과 문턱을 올린 변경이 아니다. 관련 근거를 코드 주석에 남겼다.
  - 4배 허용 그림자 정리는 기본 마스크 전경의 15%를 초과해 지우려 하면 적용하지 않도록 했다. 이 경로가 기존 밝은 직물/유약 침식의 직접 원인이었다.
  - 최대 연결 성분비 `0.50`은 완화하지 않았다. 소형(짧은 축 96px 미만) 비균일 입력은 공간장이 충분한 경계 표본을 갖지 못하므로 프레임 폴백한다. 균일한 소형 입력은 그대로 컷아웃한다.
  - 기존 기준선 진단 도구가 사용하는 private 거리/전역색 마스크 호출은 호환 경로로 유지했다. 새 추출 흐름은 이 전역색 경로를 사용하지 않는다.
- `tests/test_source_photos.py`
  - 수직 스튜디오 그라데이션에서의 컷아웃 회귀와, 기존 침식 4건(`165266`, `165267`, `165271`, `122443`)의 실제 제품 좌표 보존 회귀를 추가했다.
  - 도자기 배경 픽셀이 완전 투명해진 새 동작에 맞게 기존 fade 단언을 `<= 40`으로 조정했다.

- 기준선: 컷아웃 수행 `9/60` (15.0%), 폴백 `51/60`.
