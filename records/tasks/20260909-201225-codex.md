## 문제 (실측 데이터)

방금 평가 파일럿 6건을 실제로 생성했는데, hero 컷아웃이 제품을 지워버린 사례가 2건 나왔다.
원본 대비 비배경 픽셀 보존율:

- ceramic (청자 연화문 병): **3%** — 병이 거의 완전히 소실되고 어두운 연꽃 문양 파편만 남음
- textile: **26%** — 밝은 회색 씨실이 배경으로 판정되어 천이 뚫린 형태가 됨
- box / metalware / jewelry / furniture: 100% 정상

실제 산출물을 직접 열어서 확인할 것:
`generated/evaluation/pilot-20260909-191344/analysis-cma-122443/photos/01-hero.png` (청자, 손상)
`generated/evaluation/pilot-20260909-191344/analysis-cma-101636/photos/01-hero.jpg` (칠기함, 정상)
원본은 각 case 의 `data/evaluation/cma_real_v1/images/<asset_id>.jpg` 다.

## 원인

`src/detail_page_ai/source_photos.py` 의 `SolidBackgroundCutoutExtractor.extract` 가
**연결성 없는 순수 색거리 임계값**으로 알파 마스크를 만든다. 네 모서리 평균으로 배경색을
잡고 이미지 전체에서 그 색과 가까운 픽셀을 전부 투명으로 만들기 때문에, 밝은 제품이 밝은
배경 위에 있으면 제품 **내부** 픽셀까지 배경으로 판정되어 지워진다.

부수 문제 두 가지:
- 완화 루프 `for multiplier in (1, 2, 4)` 는 bbox 가 프레임에 닿을 때 tolerance 를 **키우는**
  방향이라 이 실패를 악화시킨다.
- 가드인 `min_foreground_ratio = 0.01` 은 "얼마나 남았나"만 보므로 3%만 남은 청자도 통과한다.
  남은 영역이 온전한 물체인지는 보지 않는다.

## 고칠 방향

1. **배경은 테두리에서 연결된 영역만으로 정의한다.**
   배경색과 가까운 픽셀을 배경 "후보"로 두되, 이미지 테두리에서 4-이웃 flood fill 로 도달
   가능한 후보만 실제 배경으로 확정한다. 도달하지 못한 내부 영역(제품 내부의 밝은 부분)은
   전경으로 유지한다. 이것이 이번 결함의 핵심 수정이다.
2. **완화 루프 방향 정리.** 연결성 기반에서는 tolerance 를 키우는 escalation 이 필요 없거나
   의미가 달라진다. 남기려면 "전경이 `max_foreground_ratio` 를 넘을 때만" 키우는 식으로
   근거를 명확히 하고, 아니면 제거하라. 지금처럼 프레임 접촉만으로 키우지 마라.
3. **가드 강화 — 망가진 마스크는 만들지 말고 None 을 반환한다.**
   전경 픽셀 중 최대 연결 성분이 차지하는 비율이 낮으면(파편화) 마스크를 신뢰할 수 없으므로
   `None` 을 반환한다. `extract` 가 `None` 이면 파이프라인은 원본 이미지로 fallback 하므로,
   제품이 지워진 결과를 내보내는 것보다 안전하다. 임계값은 스스로 정하되 그 근거를 코드
   주석과 결과 보고에 남겨라.

## 제약

- **`pillow` 외 새 의존성을 추가하지 마라.** `pyproject.toml` 의존성은 fastapi, httpx,
  pillow, pydantic-settings, python-multipart, uvicorn 뿐이다. numpy, scipy, opencv 금지.
  flood fill 은 `Image.load()` + `collections.deque` BFS 로 직접 구현하면 된다.
  입력은 대략 700x900 이므로 순수 파이썬으로 충분하다.
- **RGB 픽셀은 절대 새로 만들지 마라.** 이 클래스의 계약은 "알파 마스크만 만들고 RGB 는
  항상 디코드된 원본에서 그대로 가져온다" 이다 (`red, green, blue = source.split()`).
  이 계약을 깨면 원본 픽셀 fidelity 검증 전체가 무너진다.
- `_refine_mask` 의 1픽셀 halo 제거 동작은 유지한다.
