# Phase 1 산출물 교차 검수 — 읽기 전용

## 배경

Notion 의 Phase 1 과제(생성형 AI 직군)에 맞춰 산출물 3종을 새로 썼다.

| 과제 산출물 | 파일 |
| --- | --- |
| AI 관점 비교 분석 보고서 (AI 기능·모델·데이터·평가·안전성) | `docs/deliverables/phase1/01-ai-comparison-report.md` |
| AI 통합 영역 2개+ 후보 도출 문서 | `docs/deliverables/phase1/02-ai-integration-areas.md` |
| AI·데이터·UX 차별화 전략 문서 | `docs/deliverables/phase1/03-ai-differentiation-strategy.md` |

과제 원문 요구: 해외·국내 경쟁 서비스의 AI 기능 범위, 모델 유형, 데이터 처리 방식, 평가 방식, 안전성 이슈를
모델 카드·기술 블로그·시스템 카드 등 **공개 자료** 로 비교. 우리 서비스에 적용할 AI 통합 영역 2개 이상 도출.
추천·검색·리뷰·챗봇 등에서 차별화 전략 제안.

## 할 일 — 파일을 수정하지 마라

1. **우리 시스템에 대한 주장**을 저장소와 대조해라. 특히 02·03 의 "이후 진행 상황 / 이후 검증 상태" 문장.
   예: 인젝션 41건 중 반영 0건, 누끼 62/62, 60건 실행, 근거 3단계(image-visible/inferred/unknown),
   대표 사진 원본 고정, 초안→승인 흐름, 권리 최종 확인 상태, 챗봇 구성(BGE-M3·pgvector·BM25 하이브리드).
   근거 파일과 줄을 대고, **틀렸거나 과장된 문장**을 찾아라
2. **경쟁사 주장**은 각 문장에 붙은 출처 기호(A1, E2 …)와 짝이 맞는지 봐라. 웹 접근이 되면 출처를 열어 확인하고,
   안 되면 "출처 미확인" 으로 표시만 해라. **추측으로 맞다고 하지 마라**
3. **과제 요구 대비 빠진 것**이 있는지 봐라. 예: 해외·국내 각 2~3개 충족 여부, "추천·검색·리뷰·챗봇" 중 다룬 것
4. 표현이 사실보다 강한 곳(예: "없다"고 단정했는데 공개 자료 범위 한정이어야 하는 곳)을 찾아라
