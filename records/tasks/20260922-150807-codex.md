# 생성컷이 버려지지 않게 gallery 자리도 확보

## 지시

[구현 과제] 생성컷 여분 슬롯을 레이아웃이 쓰게 한다

## 근거 (내가 실측함, 재조사 불필요)

합죽선 매화선 실행(`generated/attached/hapjukseon-maehwa/`)에서 **생성컷 5장이
전부 버려졌다.**

```
unused_generated_photo_ids: ['lifestyle-02','detail-02','detail-03','detail-04','detail-05']
```

장인이 사진을 4장 줘서 hero·packshot·detail·lifestyle 이 원본으로 채워졌고,
생성컷은 여분 슬롯(lifestyle-02, detail-02~05)으로 밀렸는데 **뽑힌 원형
`surface-to-context` 에 `gallery` 가 없어서** 그 슬롯을 쓰는 블록이 없었다.

page_plan: hero → detail_split → statement → usage_scene → wide_image → info_table → notice → closing

`gallery` 블록은 프롬프트 규약상 `photo_ids` 로
`["detail","detail-02","detail-03","detail-04","detail-05"]` 를 쓴다.
**즉 gallery 가 있으면 생성된 detail-02~05 가 소비된다.**

## 할 일

`src/detail_page_ai/layout_archetypes.py` 의 `select_layout_archetypes` 에서,
`image_generation_enabled` 일 때 후보 풀을 **`usage_scene` 과 `gallery` 를 모두
가진 원형**으로 제한한다.

지금은 `usage_scene` 만 거르고 있다. 거기에 `gallery` 조건을 더하면 된다.

풀 크기는 내가 이미 확인했다. **25종 중 둘 다 포함이 14종**이라 충분하다.

```
gallery 포함      19종
usage_scene 포함  16종
둘 다             14종   ← 새 풀
```

기존과 같이 **걸러서 후보가 하나도 안 남으면 이전 단계 후보를 그대로 쓴다.**
단계적으로 떨어지게 하라: (둘 다) → (usage_scene 만) → (전체). 재현성(같은
sha256 → 같은 표본)은 유지해야 한다.

단언을 약하게 만들지 마라. 전체 pytest 를 돌리고 숫자를 그대로 보고하라.

### 60건 다양성 시뮬레이션

`generated/evaluation/full60-v2-20260911-110752/run_index.json`의 60개 SHA-256을 그대로 사용하고, `making_method`가 있어 25종 전체 카탈로그를 후보로 쓰는 조건으로 임시 파일럿을 만들었습니다. 두 실행 모두 `scripts/check_plan_diversity.py --candidate-pool-size 25`를 사용했으며 모델 호출은 하지 않았습니다.

| 조건 | 실제 후보 풀 | 평균 집합 일치도 | 유효 공통 블록 | 완전 일치 쌍 | 고유 시퀀스 |
| --- | ---: | ---: | ---: | ---: | ---: |
| usage_scene만 (현행) | 16종 | 62.0% | 1종 | 109쌍 | 16종 / 60건 |
| usage_scene + gallery (변경안) | 14종 | **62.5%** | **2종** | **125쌍** | **14종 / 60건** |

변경안은 평균 일치도 **+0.5%p**, 유효 공통 블록 **+1종**, 완전 일치 쌍 **+16쌍**, 고유 시퀀스 **-2종**으로 다양성이 나빠졌습니다. 카탈로그 기준 후보 풀은 25종으로 고정했고, 게이트 임계값은 조정하지 않았습니다. `check_plan_diversity.py` 신규 기준 판정은 현행과 변경안 모두 `[FAIL]`이었습니다(완전 일치 쌍 관측 109쌍/125쌍, 기준 p95 86쌍).
