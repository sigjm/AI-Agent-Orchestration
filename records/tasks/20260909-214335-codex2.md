## 지시

## 목표

컷아웃 마스크 수정과 장신구 씬 분기 추가가 실제 생성물에 반영되는지 확인한다.
평가 파일럿 6건을 재생성하고, 두 개의 품질 게이트를 돌려 결과를 보고한다.

이 작업은 **실행과 측정**이다. 코드를 고치는 작업이 아니다.

## 배경

직전 파일럿(`generated/evaluation/pilot-20260909-191344`)에서 hero 컷아웃이 제품을 지운
사례가 2건 나왔다. ceramic 보존율 3%, textile 26%. 이후 두 가지가 수정됐다.

1. `SolidBackgroundCutoutExtractor` 가 경계 연결 flood fill 로 배경을 정의하도록 바뀌었다.
   추출기 단독 측정으로는 textile 26% -> 85%, ceramic 3% -> 62% 로 개선됐다.
   **다만 이건 추출기만 따로 돌린 수치이고, 파이프라인 전체를 통과한 결과는 아직 없다.**
2. `_product_scene_direction` 에 장신구 분기가 추가되어 목걸이가 metal 분기에서 벗어났다.

## 실행 순서

1. 모델 서버가 살아 있는지 먼저 확인한다.
   `http://127.0.0.1:11234/v1/models` 에 `ddalcu/Qwen3.8-27B-MLX-Serve-4bit` 와
   `mlx-community/flux2-klein-9b-4bit` 가 있어야 한다. 없으면 중단하고 보고하라.
   **서버를 네가 띄우거나 끄지 마라.**

2. 재생성을 실행한다.
   ```
   .venv/bin/python scripts/run_eval_pilot.py --text-timeout 900 --image-timeout 900
   ```
   **건당 4~6분, 전체 30분 이상 걸린다.** 한 번에 기다리다 도구가 끊기면 진행 상황을 잃으므로,
   출력을 로그 파일로 넘기고 백그라운드로 돌린 뒤 주기적으로 로그와
   `run_index.json` 을 확인하는 방식을 권한다. 도중에 중복 실행하지 마라.
   새로 생기는 출력 디렉터리 이름(`generated/evaluation/pilot-<타임스탬프>`)을 기록해 둔다.

3. 재생성이 끝나면 게이트 두 개를 새 디렉터리에 대해 실행한다.
   ```
   .venv/bin/python scripts/check_cutout_fidelity.py --pilot-dir <새 디렉터리>
   .venv/bin/python scripts/check_scene_direction_coverage.py --pilot-dir <새 디렉터리>
   ```
   각각의 **출력 표와 종료 코드**를 그대로 기록한다.
