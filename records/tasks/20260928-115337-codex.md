# 이미지 생성 steps 를 설정으로 받게 하기 (LOCAL_IMAGE_STEPS)

## 지시

# 배경

로컬에서 이미지 모델을 FLUX.2-klein 대신 **Qwen-Image-2.1** 로 바꿔 평가하려 한다.
모델은 이미 `LOCAL_IMAGE_MODEL` env 로 바꿀 수 있다. 그런데 steps 가 막혀 있다.

- `src/local_detail_page_ai/clients.py` 의 `MlxServeImageClient`·`SglangImageClient` 는 `steps: int = 4` 기본값
- `src/local_detail_page_ai/factory.py` (110행 근처)가 두 클라이언트를 만들 때 **steps 를 넘기지 않는다**
- 4 는 FLUX.2-klein(4-step 증류 모델)용 값이다. Qwen-Image-2.1 은 증류 모델이 아니라 기본 40 steps 다.
  4 로 돌리면 모델 비교 자체가 무의미해진다

# 할 일

1. `src/detail_page_ai/config.py` 에 `local_image_steps: int` (alias `LOCAL_IMAGE_STEPS`, **기본 4**, `ge=1`, 적당한 상한) 추가.
   기존 `local_image_timeout_seconds` 옆에, 같은 스타일로
2. `factory.py` 에서 `MlxServeImageClient`·`SglangImageClient` 생성 시 이 값을 `steps=` 로 넘겨라
3. **기본값 4 는 절대 바꾸지 마라.** 기존 동작(FLUX)은 env 를 안 주면 그대로여야 한다.
   `clients.py` 의 steps 관련 주석("A/B 증거 전엔 올리지 말라")도 그대로 둬라
4. `runner.py:148` 에도 `MlxServeImageClient(` 생성이 있다. 이게 factory 와 다른 경로인지 확인하고,
   같은 설정을 받아야 하는 경로면 똑같이 넘겨라. 아니면 왜 아닌지 보고해라

# 테스트

- env 미설정 시 두 클라이언트의 steps == 4
- `LOCAL_IMAGE_STEPS=40` 이면 40 이 **실제 요청 필드 `num_inference_steps`** 까지 전달되는지 (가짜 transport 로 확인)
- 기존 테스트 약화 금지

- 모델 기본값(`LOCAL_IMAGE_MODEL`)은 바꾸지 마라
