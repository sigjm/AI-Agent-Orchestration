## 지시

앞서 취소한 9B FP8 작업과는 다른 새 작업입니다. 관리자 최종 결정: **서버 이미지 모델은 FLUX.2-klein-9B 를 4bit 로 양자화한 파이프라인**을 쓴다. 관리자(오케스트레이터)가 설정 파일은 이미 고쳤습니다. 당신은 **문서 두 개만** 현재 설정에 맞추세요. 브랜치 `deploy/ubuntu`, 커밋하지 마세요. `docker-compose.yml`, `.env.example`, `docker/`, `src/`, `tests/` 는 건드리지 마세요 — 이미 확정됐습니다.

## 확정된 설정 (먼저 이 파일들을 읽고 문서를 맞추세요)
- `.env.example`: `IMAGE_MODEL_PATH=circulus/FLUX.2-klein-9B-bnb-4bit`. `IMAGE_PERFORMANCE_MODE` 변수는 **삭제됨**.
- `docker-compose.yml` 의 `sglang-image` 명령: `sglang serve --model-path circulus/FLUX.2-klein-9B-bnb-4bit --served-model-name flux-klein --host 0.0.0.0 --port 30001 --num-gpus 1 --dit-cpu-offload false --text-encoder-cpu-offload false`. `--performance-mode`, `--pin-cpu-memory` 는 **제거됨**.
- `docker/sglang-diffusion.Dockerfile`: `sglang[diffusion]==0.5.19` 와 함께 `bitsandbytes==0.50.2` 설치.
- 텍스트 서버는 변경 없음(`cyankiwi/Qwen3.8-27B-AWQ-INT4`, `--mem-fraction-static 0.50`).

## 관리자가 확인한 근거
- `circulus/FLUX.2-klein-9B-bnb-4bit`(HF API 파일 목록·config.json): diffusers `Flux2KleinPipeline` 전체 구성. transformer 4.36 GiB, text_encoder(Qwen3ForCausalLM) 5.66 GiB, vae 0.16 GiB, 합계 약 10.2 GiB. transformer·text_encoder 모두 `quantization_config` 에 bitsandbytes 4bit(`bnb_4bit_quant_type: nf4`, `bnb_4bit_use_double_quant: true`, compute dtype bfloat16). 게이트 아님(`gated: False`), 저장소 카드에 라이선스 표기 없음. 로컬 MLX 의 `mlx-community/flux2-klein-9b-4bit`(9.5 GB)과 같은 성격.
- 원본 `black-forest-labs/FLUX.2-klein-9B` 는 FLUX Non-Commercial License. 위 저장소는 그 커뮤니티 양자화본이다(사실만 기록; 판단·권고 쓰지 말 것). 관리자 결정으로 채택.
- SGLang 0.5.19 wheel 소스: `sglang/multimodal_gen/runtime/layers/quantization/bitsandbytes.py` 의 `BitsAndBytesConfig` 는 "pre-quantized bitsandbytes 4-bit checkpoints" 용. 단위 테스트 `test/unit/test_transformer_quant.py`(HF config 의 bitsandbytes nf4 설정 해석), `test/unit/test_text_encoder_loader.py`(표준 bitsandbytes 텍스트 인코더는 transformers 로 위임, `test_bitsandbytes_native_load_requires_resident_encoder` — 텍스트 인코더는 GPU 상주 필요)가 있음. `bitsandbytes` 는 sglang 의 `test` extra 에만 있어 diffusion 설치에 포함되지 않음 → Dockerfile 에 추가한 이유.
- SGLang 0.5.19 `server_args.py` `_adjust_offload`: 이미지 생성 작업은 `dit_cpu_offload`, `text_encoder_cpu_offload` 를 명시하지 않으면 True 로 켠다 → 4bit 텍스트 인코더 상주 조건과 충돌하므로 둘 다 `false` 명시.
- 메모리(가중치 기준 하한): GPU 44.7 GiB = 텍스트 서버 22.35 GiB(0.50) + 이미지 약 10.2 GiB = 32.6 GiB, 여유 약 12.1 GiB(활성화·CUDA 컨텍스트 2개). CPU 오프로드 없음 → 시스템 RAM 32 GiB 압박 없음.

- **6.6 첫 배포 측정 체크리스트**:
  - bitsandbytes 4bit SGLang 로딩 로그 확인, 텍스트 인코더/트랜스포머 GPU 상주 확인, `nvidia-smi` 점유 실측(텍스트 ~22.4 GiB, 이미지 ~10.5 GiB, 총합 < 35.0 GiB), 로컬 Mac MLX 9b-4bit 결과와의 품질 비교 항목 추가. 실패 시 대안(`FLUX.2-klein-4B`) 롤백 경로 제시.
