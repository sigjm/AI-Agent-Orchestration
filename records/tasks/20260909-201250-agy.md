# 컷아웃 보존율 회귀 판정 도구

- 워커: agy
- 발행: 2026-09-09 20:12:50
- 지휘: Claude Code (오케스트레이터 세션)

## 지시

## 목표

생성 산출물의 제품 컷아웃이 원본을 얼마나 보존했는지 자동으로 판정하는 스크립트
`scripts/check_cutout_fidelity.py` 를 새로 만든다. 재생성 전후 회귀 비교에 쓸 도구다.

## 왜 필요한가

방금 파일럿 6건에서 hero 컷아웃이 제품을 지워버린 사례가 2건 나왔다 (ceramic 3% 보존,
textile 26% 보존). 그런데 기존 자동 검증 지표는 전부 통과했다. React 스키마, 원본 SHA-256,
imageId 해석, 합성 fidelity 모두 PASS 였다. 합성 fidelity 검증은 "선언된 변환이 그대로
적용됐는가"만 보기 때문에, 마스크가 제품을 지워도 통과한다. 이 구멍을 메우는 도구다.

## 입력

파일럿 실행 디렉터리 (`--pilot-dir`, 예: `generated/evaluation/pilot-20260909-191344`).
그 안의 `run_index.json` 에 case 별 `image_path`(원본), `output_dir`, `category`, `success` 가 있다.
각 case 의 `output_dir/photos/` 에 `01-hero.*`, `02-packshot.*`, `03-detail.*` 등이 있고,
확장자는 jpg 와 png 가 섞여 있다. **확장자를 png 로 가정하지 마라.** 실제로 그 실수로
측정이 틀렸던 적이 있다.

## 판정 방법

원본과 산출 photo 각각에서 "비배경 픽셀 비율"을 구하고, 그 비율이 원본 대비 얼마나
남았는지를 보존율로 삼는다.

- 두 이미지를 같은 크기(예: 256x256)로 리샘플하고 grayscale 로 변환한다.
- 밝기 임계값(예: 235) 미만인 픽셀을 "비배경(잉크)"으로 센다.
- 보존율 = 산출물 잉크 비율 / 원본 잉크 비율
- 판정: 0.6 초과 = OK, 0.25 미만 = 심각 손실, 그 사이 = 부분 손실

이 임계값은 인자로 덮어쓸 수 있게 하되 기본값은 위와 같이 둔다.
`pillow` 만 사용하고 numpy 등 새 의존성을 추가하지 마라 (프로젝트 의존성에 없다).

## 출력

- 표준출력에 카테고리별 표: 카테고리, case_id, photo 역할, 원본 잉크 비율, 산출 잉크 비율,
  보존율, 판정
- `--json <경로>` 를 주면 같은 내용을 JSON 으로도 저장
- 심각 손실이 하나라도 있으면 **종료 코드 1**, 전부 OK 면 0.
  (재생성 후 회귀 판정을 자동화하기 위한 것이다.)
