## 지시

## 문제 (내가 확인한 사실)

`simulate_catalog_baseline` 이 `rng.sample(layout_sets, effective_k)` 로 **비복원 추출**을 한다.
그래서 시뮬레이션 배치 안에는 같은 원형이 절대 두 번 나오지 않고, 완전 일치 쌍의
기대값이 구조적으로 0 이 된다. 그 위에 얹힌 `DEFAULT_MAX_IDENTICAL_PAIRS = 1` 은
모델에서 유도된 값이 아니라 손으로 정한 값이다.

실제 파이프라인은 상품마다 독립적으로 원형을 고르는 **복원 추출**이다. 게다가
`effective_k = min(sample_size, len(layout_sets))` 라서, 60건 배치에서는 기준선이
25건만 시뮬레이션한다 — 60개 상품이 25종에서 겹치지 않게 뽑히는, 불가능한 상황을
모델링하고 있다.

결과적으로 완전 일치 쌍 게이트는 60건에서 어떤 설계로도 통과하지 못한다.
현행 운영 상태도 99쌍으로 미달이다. 항상 실패하는 게이트는 신호가 아니다.

## 할 일

1. 기준선 시뮬레이션이 **실제 배치 크기 N 만큼 복원추출**하도록 고친다.
   `effective_k = min(sample_size, len(layout_sets))` 로 잘라내는 부분을 없앤다.
   N 은 평가 대상 케이스 수다.
2. 같은 시뮬레이션에서 **완전 일치 쌍 개수의 분포**도 모은다. 이미 jaccard 와
   effective_common 에 대해 mean/p95 를 내고 있으니 같은 방식으로 낸다.
3. 완전 일치 쌍 임계값을 그 시뮬레이션의 **p95** 에서 유도한다.
   `DEFAULT_MAX_IDENTICAL_PAIRS` 고정값은 CLI 명시 지정(`--max-identical-pairs`)이
   있을 때만 쓰는 오버라이드로 남기고, 기본은 유도값을 쓴다.
   jaccard 임계값이 baseline + delta 로 유도되는 것과 같은 구조로 맞춰라.
4. 카탈로그를 못 읽을 때의 fallback baseline 에도 대응하는 키를 넣어라.
5. 출력 리포트에 "기대치 N쌍(p95) / 관측 N쌍" 이 보이게 하라. 지금 jaccard 가
   "카탈로그 기대치 54.5% + 10.0%p" 를 보여주는 것과 같은 수준으로.

## 절대 하지 말 것

- **우리 결과를 보고 임계값을 맞추지 마라.** 임계값은 귀무모형(카탈로그에서
  무작위 추출)에서만 유도돼야 한다. 우리 실행 결과는 유도 과정에 들어가면 안 된다.
- jaccard 의 `max_jaccard_delta` 기본값(0.10)은 건드리지 마라. 별도 안건이다.
- 다른 게이트의 판정 로직을 느슨하게 만들지 마라.
- `assets/references/detail-page-layouts.json` 은 건드리지 마라.

## 테스트

`tests/test_plan_diversity.py` 에 기준선/임계값 관련 테스트가 있다. 새 모델에 맞게
고치되 단언을 약하게 만들지 마라. 최소한 다음을 새로 보장하라:
- 복원추출이므로 N 이 카탈로그 종수보다 커도 시뮬레이션이 동작한다
- N 이 커질수록 완전 일치 쌍 임계값이 커진다 (단조성)
- 같은 seed 면 기준선이 재현된다

`.venv/bin/python -m pytest` 전체를 돌리고 숫자를 그대로 보고하라.

## 결과

### 변경 내용

- `scripts/check_plan_diversity.py`
  - 카탈로그 baseline을 `rng.choice` 기반 N회 복원추출로 변경했다. 이제 60건 실행도 25종으로 잘리지 않고 `sample_size=60`으로 시뮬레이션한다.
  - 동일한 시뮬레이션에서 exact-match 쌍 수의 평균과 P95(`mean_identical_pairs`, `p95_identical_pairs`)를 계산한다.
  - `max_identical_pairs` 미지정 시 baseline P95를 동적 기준으로 사용하고, `--max-identical-pairs`를 명시한 경우에만 고정 override를 사용한다. `DEFAULT_MAX_IDENTICAL_PAIRS=1`은 명시 override용으로 유지했다.
  - `--candidate-pool-size`를 추가했다. 미지정 시 카탈로그 전체 25종, 지정 시 해당 크기의 후보 풀을 사용한다.
  - 카탈로그 fallback에도 identical-pair 기준 키를 추가하고, 리포트에 `기대치 N쌍(p95) / 관측 N쌍`을 출력한다.
- `tests/test_plan_diversity.py`
  - 복원추출의 실제 N 유지, candidate pool override, N 증가에 따른 identical-pair P95 증가, fallback 키, 동적 기준/CLI override, 리포트 출력을 검증하도록 보강했다.
