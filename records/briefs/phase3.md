## 문서 구성 (이 순서로 5개 장)
1. **AI 영역 구현 코드·체크포인트** — 무엇을 만들었고 현재 어디까지 와 있는가
2. **에러 분석** — 무엇이 어떻게 틀렸고 어떻게 잡았는가
3. **실험 보고서** — 개선 가설과 결과 (1~12차)
4. **추론 API 구성** — 모델·서빙·클라이언트 구성
5. **BE/FE 통합 인터페이스 명세** — 계약과 현재 연동 상태

앞에 **요약 한 장**을 둔다. 뒤에 **원본 문서 색인**을 둬서 각 장이 어느 파일에서 왔는지 링크한다.

## 반드시 지킬 것
- **사실만 적는다.** 이 저장소에는 **사람 평가 점수도 설문 결과도 없다.** 만들지 말 것.
- **서버 GPU 에서는 아직 한 번도 실행되지 않았다.** 검증된 것처럼 쓰지 말 것.
- 수치는 원본 문서에서 그대로 가져오고, 어느 차수·어느 실행의 수치인지 함께 적는다. 기억이나 추정으로 쓰지 말 것.
- 원본 5종과 차수 기록을 **수정하지 않는다.** 새 파일만 만든다.
- 요약이되 **자체 완결**이어야 한다. 원본을 열지 않아도 읽히게 쓴다. 다른 문서를 참조할 때는 링크만 남기지 말고 수치를 함께 적는다.

## 최신 상태로 반영해야 하는 것 (원본보다 새로운 사실)
- 테스트는 현재 **369개 통과**다. 직접 `.venv/bin/python -m pytest -q` 로 확인하고 그 수를 쓸 것.
- 사진 배정이 바뀌었다: **장인이 올린 사진을 먼저 역할에 배정하고 모자란 만큼만 생성**한다. 생성 장수 상한은 `MAX_GENERATED_PHOTOS`(0~12, 기본 5)이며 `0`이면 생성하지 않는다. (커밋 `07ce5da`, `070d8c2`)
- 서버 추론은 **SGLang** 단일 엔진으로 텍스트(30000)·이미지 확산(30001) 두 서버를 띄운다. Mac 로컬 개발은 MLX.
- **BE 연동은 현재 양방향 모두 실패한다.** 실측 기록이 `docs/evaluation/be-integration-test-2026-09-17.md` 에 있고, 협의 문서는 `docs/api/be-ai-integration-negotiation.md` 다. 5장에 이 상태를 반드시 반영할 것.
- 추천 챗봇은 이 저장소에 없다. `Jangingmall/GenAI` 의 `chat_bot/` 이 담당한다.
