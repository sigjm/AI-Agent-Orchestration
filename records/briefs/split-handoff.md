## 1) `be-handoff-2026-09-17.md` — BE 팀에 넘길 것만

**BE 코드/설정만 고치면 되는 항목만** 담습니다. 우리 할 일과 합의 항목은 **넣지 마세요**(맨 끝에 링크만).

담을 항목 (원문에서 그대로 옮기되 번호를 `BE-1`부터 다시 매김):
| 새 번호 | 원문 | 내용 |
| --- | --- | --- |
| BE-1 | R-1 | HTTP/1.1 고정 — **차단**. 원시 요청 캡처와 검증 결과 포함 |
| BE-2 | R-11 | `@Async` 자기 호출 — **차단**. R-4(202 안 FAILED)의 원인이므로 **하나로 합칠 것** |
| BE-3 | R-2 | 상품 동기화를 챗봇으로 라우팅 |
| BE-4 | R-5 | 콘텐츠 생성 재시도 미구현 (계약서 3-6) |
| BE-5 | R-6 | 계약서 5-3 과 코드 불일치 — 정본 확정 |
| BE-6 | R-7 | 로컬 가이드의 `.env` 미동작 |
| BE-7 | R-10 | `AI_SGLANG_URL`·`AI_OLLAMA_URL` 이름이 실제 엔진과 반대 |
| BE-8 | R-9 일부 | AWS 배포 시 BE 가 설정할 것 — AI 주소·포트(**8000**), 콜백용 BE 내부 주소 제공 |

- **R-4 는 BE-2 에 흡수**합니다. 같은 원인이므로 따로 두면 두 번 고치려 합니다.
- 각 항목은 **증상 → 근거(파일:행 또는 로그) → 요청** 순으로.
- 맨 앞에 한 줄 요약표(번호·제목·급함).
- **BE-1 과 BE-2 가 차단 항목**임을 앞에서 분명히.

## 2) `ai-worklist-2026-09-17.md` — 우리가 할 일

우리 저장소에서 고칠 것만. **BE 에 보내는 문서가 아니라 우리 작업 목록**입니다.

담을 항목:
- 설계 결함 (BE 가 뭘 하든 고쳐야 하는 것): 콜백 경로 조립 불가, ACK 스키마 경직(`extra="forbid"`), 이미지 바이트만 수용
- 맞추는 것: `POST /ai/products` 경로 추가, JSON 본문 수용, 숫자 ID, 힌트 필드명 매핑(`product_name`↔`productName` 등)

**각 항목에 `닿는 파일` 열을 반드시 넣으세요.** 구현자가 어디를 고칠지 바로 알 수 있어야 합니다. 예: `src/detail_page_ai/backend_client.py`, `src/detail_page_ai/ai_dto.py`, `src/detail_page_ai/app.py`. 파일은 **실제로 확인하고** 적을 것. 추측 금지.

**차단 표시**: `/ai/products` 응답 형식은 BE 회신(아래 D-1) 전에는 구현할 수 없습니다. 그 의존을 명시하세요.
