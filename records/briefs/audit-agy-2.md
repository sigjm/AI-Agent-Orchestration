# 추가 검수 — 아직 아무도 보지 않은 영역

앞 작업과 동일하게 **파일을 수정하지 마세요.** 발견만 보고합니다.

## 담당 파일 (앞 작업과 겹치지 않음)
- docs/refactoring/*.md (5개)
- docs/superpowers/plans/*.md, docs/superpowers/specs/*.md (7개)
- docs/data/*.md, docs/references/*.md
- scripts/ 아래 전체 (실행 가능 여부·죽은 스크립트)
- web/ 아래 전체

## 확인 항목
1. **죽은 참조**: 이 문서들이 가리키는 스크립트·모듈 경로 중 실제로 존재하지 않는 것. 단, `docs/refactoring/` 과 `docs/superpowers/plans/` 는 **시점 기록(제안·진단)** 이므로, 제안만 하고 구현되지 않은 모듈 경로가 없는 것은 **정상**이다. 그런 것과 "과거에 존재했다가 이동/삭제된 경로를 현재형으로 가리키는 것"을 구분해서 보고할 것.
2. **scripts/ 죽은 스크립트**: `scripts/` 의 각 .py / .mjs / .sh 가 (a) 다른 코드·문서에서 참조되는가 (b) import 에러 없이 로드되는가. 참조도 없고 로드도 안 되는 것 목록.
3. **web/**: `web/` 의 각 파일이 실제로 쓰이는가. 어디서도 참조되지 않는 파일 목록. (주의: FE 렌더러 구현은 우리 팀 범위가 아니다. 구현 제안은 하지 말고 참조 여부만 보고.)
4. **아티팩트 페이지 대조**: 내가 인프라팀에 보낼 페이지를 만들었다. 그 원본인 `docs/operations/eks-workload-spec.md` 의 내용 중, **외부에 나가면 곤란한 서술**(내부 오케스트레이션 사정, 워커 이름, 미공개 경로, 팀 내부 갈등 서술 등)이 있는지 확인. 있으면 행 번호와 함께 보고.
